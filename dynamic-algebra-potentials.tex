\title{Compositional Dynamics for Learning and Physics}

\author{David I. Spivak}

\date{\vspace{-.2in}}

\maketitle

\begin{abstract}
We give a single compositional setting in which gradient-based learning and Hamiltonian-style mechanics appear as functorial semantics. The syntax is a category $\potlens$ whose objects are input-output interfaces (pairs of manifolds) and whose morphisms are smooth rewiring diagrams: potentialized lenses consisting of a reactive parameter space, smooth forward and backward routing maps, and a real-valued potential.

The technical heart is what we call a \emph{Moore internalization}, a lax monoidal functor $\Lens{\cat{C}}\to\cat{C}$ associated to any symmetric monoidal closed category $\cat{C}$. Using it, we provide two functors $\Phi_{\phase},\Phi_{\conf}\colon\potlens\to\org$ into the bicategory $\org$ of polynomial coalgebras, which we take as the semantics category. $\Phi_{\phase}$ stores both position and momentum; $\Phi_{\conf}$ stores only position. When applied to a parameterized function, $\Phi_{\conf}$ recovers the gradient descent training algorithm, with backpropagation as the lens' backward pass. When applied to a collection of particles wired together in series, $\Phi_{\phase}$ recovers the discrete wave equation.
\end{abstract}

%====================================================================
\chapter{Introduction}\label{ch.intro}
%====================================================================

There is a commonality in Hamiltonian dynamics and gradient descent, namely an isomorphism of the form $T^*M\cong TM$ transforming covectors into vectors that change the state. In the vector-space setting below, this covector-to-update structure is what we call \emph{reactive}. In Hamiltonian dynamics, it is the \emph{symplectic sharp} map on phase space; in gradient descent it is the Riemannian metric, which determines the learning rate on parameter space. And in each case, the dynamics is compositional: local subsystems---each with their own dynamics---can send each other information by which to compose into an integrated dynamical system.

The goal of this paper is to build a compositional syntax for such smooth reactive, potential-driven systems, including their time-varying couplings, and a functorial semantics that turns this syntax into explicit discrete update rules.

%--------------------------------------------------------------------
\section{Motivation for smooth rewiring diagrams}\label{sec.intro_smooth_rewiring}
%--------------------------------------------------------------------

Operads are a natural categorical setting for establishing compositionality results. An operad $\cat{W}$ establishes a composition syntax---what sorts of diagrams can be composed---and a functor $\cat{W}\to\smset$ establishes the corresponding semantics. For example
\[
\begin{tikzpicture}[oriented WD, bb port length=4pt, bb port sep=1.5, bb min width=.35cm, bbx=.4cm, bby=.8ex, baseline=(box1), particle/.style={path picture={\fill (path picture bounding box.center) circle (2.4pt);}}]
  \def\N{6}
  \node[bb={1}{1}, particle] (box1) {};
  \foreach \i [evaluate=\i as \prev using int(\i-1)] in {2,...,\N} {
    \node[bb={1}{1}, particle, right=.7 of box\prev] (box\i) {};
    \draw (box\prev_out1) -- (box\i_in1);
  }
  \node[bb={0}{0}, fit={(box1) (box\N)}] (Y) {};
  \node[coordinate] at (Y.west|-box1_in1) (Y_in1) {};
  \node[coordinate] at (Y.east|-box\N_out1) (Y_out1) {};
  \draw (Y_in1) -- (box1_in1);
  \draw (box\N_out1) -- (Y_out1);
\end{tikzpicture}
\]
For interfaces $b_1,\ldots,b_K,c$, a morphism $\phi\colon b_1,\ldots,b_K\to c$ in $\cat{W}$ represents an arrangement of $K$ internal boxes, with interfaces $b_1,\ldots,b_K$, inside an external box with interface $c$. The picture above is the case $K=6$: it places six boxes of the same type in a chain inside a box of that type. As syntax, it records the architecture of the chain---the types of each wire and how boxes are connected---it does not say what the boxes do, what signals pass along each wire, or how strongly one box affects the next.

In the examples below we need a richer composition syntax: one where the effective coupling is itself part of the data and may change through time, depending on continuous parameters, on the values exposed by the internal boxes, and on values received by the external box. For example, consider an adaptive spring material for which each connecting edge has a variable spring constant that can be controlled from outside the system, in conjunction with internal adaptation governed by a chosen potential $U$. 

We call these richer composition patterns \emph{smooth rewiring diagrams}. And instead of interpreting them in $\smset$, where the semantics is static, we interpret them in $\org$, whose morphisms are polynomial coalgebras: input-output systems with state that changes in time. Thus a $0$-ary morphism can represent a component, such as a single particle, rather than only an empty box, and a $K$-ary morphism can represent an adaptive interaction among $K$ components.

The choice to have semantics land in $\org$, whose morphisms are polynomial coalgebras, is the choice to take polynomial functors seriously as input-output interfaces. Polynomial functors are perhaps the simplest setting in which alternatives and requirements coexist: they are built from one representable $\yon$ by coproducts and products---the free distributive category on a single object---so a polynomial
\[
p=\sum_{i:I}\yon^{p[i]}
\]
is just a family of \emph{directions} $p[i]$ indexed by a family of \emph{positions} $i:I$. We regard positions as the possible outputs and the directions as the inputs accepted at that output. A $p$-coalgebra $S\to p(S)$ is then a deterministic dynamical system with state: given a state $s$ it specifies an output position and, for every acceptable input direction, specifies a next state. 

Just as the free coproduct completion of a single object has all limits---i.e.\ $\smset$ has a great deal of structure emerging unexpectedly when simply asking for coproducts---much of the usefulness of $\poly$ comes from structure that emerges unexpectedly from the free-distributive description. For example, as recalled in \cref{sec.poly}, polynomials can be understood as functors $\smset\to\smset$, and under this interpretation they compose by substitution, internalized as a monoidal product $\tri$ on $\poly$. This leads naturally to considering polynomial monads, polynomial comonads, and polynomial coalgebras, all of which will be relevant to us.

But most relevantly for smooth rewiring, $\poly$ also carries the Dirichlet product $\otimes$, which combines interfaces in parallel, and this monoidal structure is closed. A map of polynomials $p\to q$ can be understood as a static coupling pattern: it sends each output position of the internal interface $p$ to an output position of the external interface $q$, and sends each compatible input direction of $q$ back to an input direction of $p$. Thus the $K$-many internal interfaces of a wiring diagram combine as $p_1\otimes\cdots\otimes p_K$, and a static wiring into an external interface $q$ is a map $\varphi\colon p_1\otimes\cdots\otimes p_K\to q$.

Because $\poly$ is monoidal closed, such maps are equivalently the positions of the internal hom
\[
w\coloneqq\ihom{p_1\otimes\cdots\otimes p_K,q},
\]
so a fixed $\varphi$ is the same thing as a one-state coalgebra on the polynomial $w$. To make the rewiring dynamic, we replace that one-state coalgebra by an arbitrary coalgebra $S\to w(S)$: its state $s:S$ outputs the current wiring pattern $\varphi_s$, and each acceptable input direction determines the next state $s'$. These internal-hom coalgebra categories are the morphisms in $\org$. We will explain all this in detail in \cref{sec.poly_dynamic_bg}.

%--------------------------------------------------------------------
\section{From smooth data to dynamics}\label{sec.intro_smooth_to_dynamics}
%--------------------------------------------------------------------

The bridge from manifolds to polynomial functors is the cotangent functor $\cot\colon\mfd\to\poly$. It sends a manifold $M$ to the polynomial
\[
\cot{M}\coloneqq\sum_{m\in M}\yon^{T_m^*M},
\]
whose positions are points $m\in M$ and whose directions are covectors at $m$. A smooth map $f\colon M\to N$ acts forward on positions by $f$ and backward on directions by cotangent pullback $(T_mf)^\top$. Crucially, $\cot$ is strong symmetric monoidal: $\cot{M\times N}\cong\cot{M}\otimes\cot{N}$. Thus parallel products of polynomial interfaces correspond to ordinary products of manifolds.

It remains to describe the source syntax: ordinary smooth data that will be sent through $\cot$ and then converted into polynomial update rules. A neural network, for example, begins as a smooth map $f\colon V\times \rr^{m}\to\rr^{n}$: a choice of parameter, input, and output manifolds, together with a model map. Smooth rewiring diagrams generalize this familiar situation in three ways. First, an ordinary manifold $M$ becomes only one component of an interface $\binom{\inpt M}{\outp M}$, namely the output side $\outp M$; the input side $\inpt M$ is an ordinary smooth port for information supplied by the surrounding system, distinct from any cotangent gradient signal. Thus the old manifolds $\rr^m,\rr^n$ become output sides $\outp M,\outp N$, and the old model map $f$ becomes the output map $\outp f$. Second, a morphism has both an output map $\outp f$ and an input map $\inpt f$, so the syntax can specify how external inputs are routed back to internal interfaces. Third, the parameter space $V$ is made reactive, and we add a potential $U\colon V\times\outp{M}\times\inpt{N}\to\rr$, whose differential contributes to the eventual update rule.

The first two pieces, $\outp f$ and $\inpt f$, are exactly the shape of a lens: a map $\outp f\colon \outp M\to\outp N$ together with a map $\inpt f\colon\outp M\times\inpt N\to\inpt M$. Lenses are a standard language for bidirectional interaction, appearing in bidirectional programming and database theory, compositional game theory, and categorical accounts of backpropagation~\cite{bohannon2006relational,johnson2012lenses,hedges2017coherence,fong2019backprop}. In our manifold setting, these two maps route output and input data between the internal boxes and the external box in a composable way. 

To add the remaining pieces, we use two standard categorical devices. The potential $U$ is packaged by passing from lenses to the coKleisli category $\lmfd^\rr$ for the comonad on $\lmfd$ induced by the monad $\rr\times\blank$ on $\mfd$: informally, the backward direction now handles both inputs and a real number, in the sense of monadic lenses~\cite{abou2016reflections}. Reactive parameters are added by the Para construction, which packages parameterized maps compositionally~\cite{capucci2024actegories}. The resulting category is
\[
\potlens\coloneqq\para{\rvect}{\lmfd^\rr};
\]
we call its morphisms \emph{potentialized lenses}. Under the semantics functor $\potlens\to\org$, the parameters and potential let the effective coupling not only transport information but also contribute to the update rule.

The passage from lenses to polynomial coalgebras is mediated by a functor we call \emph{Moore internalization}. In any symmetric monoidal closed category, a lens interface $\lensob c$ can be internalized as $\outp c\otimes\ihom{\inpt c,I}$ (\cref{prop.Theta}). In $\poly$, this sends the ordinary set-lens interface $\binom{A}{B}$, represented by $\binom{A\yon}{B\yon}$, to the monomial polynomial $B\yon^A$ (\cref{ex.moore}); coalgebras on these monomials are precisely Moore machines~\cite{moore1956gedanken}, hence the name. 

Together, $\cot$ and Moore internalization turn ordinary smooth data---output routing, input routing, a reactive parameter, and a potential---into data for a discrete dynamical system, i.e.\ a polynomial coalgebra. At that point, the remaining choice for this paper is how the reactive parameter $V$ and the carrier $S$ of the coalgebra relate, giving the two semantics functors $\Phi_{\conf},\Phi_{\phase}\colon\potlens\to\org$. In the configuration semantics $\Phi_{\conf}$, taking $S=V$, the state is just the current parameter value; this gives Newton's method and gradient descent for parameterized neural networks, with backpropagation as the lens backward pass. In the phase semantics $\Phi_{\phase}$, taking $S=T^*V$, the state also carries momentum; this gives Hamiltonian-style updates, and when applied to a chain of particles joined by ideal linear springs, it recovers the discrete wave equation. This is the sense in which smooth rewiring diagrams are syntax: they specify the smooth interaction data before the choice of coalgebraic state presentation turns that data into dynamics.

\section{Relation to open energy-driven systems}\label{sec.related_cls}
%--------------------------------------------------------------------

The closest predecessor of this paper is Capucci--Lynch--Spivak~\cite{capucci2024organizing} (hereafter CLS), which identifies the shared reactive structure $T^*X\to TX$ behind Hamiltonian mechanics and gradient descent and builds a functorial semantics from open energy-driven systems to open ODEs. Whereas we construct discrete-time semantics $\Phi_{\conf},\Phi_{\phase}\colon\potlens\to\org$, they construct continuous-time semantics $\mathrm{collapse}\circ T^*\colon\mathbf{OpenErg}\to\mathbf{COrg}$, where $\mathbf{COrg}$ is their continuous-time analog of $\org$.

Neither their framework nor the one in this paper subsumes the other. There is a common subcategory $\cat{R}$ whose objects are manifolds and whose morphisms $M\to N$ are---in CLS notation---tuples $(V,\sharp_V,w,E)$ where
\[
(V,\sharp_V):\rvect,\qquad
w\colon V\times M\to N,\qquad
E\colon V\times M\to\rr.
\]
There is a wide strong monoidal functor $\cat{R}\to\mathbf{OpenErg}$ and a fully faithful strong monoidal functor $\cat{R}\to\potlens$, the latter sending $M$ to $\binom{\rr^0}{M}$, output map $\outp f\coloneqq w$, unique input map $\inpt f\coloneqq !$, and potential $U\coloneqq E$. There is also a semantic comparison. 
\begin{proposition*}[Proven as \cref{prop.euler_submersion_lenses}]
There is a category $\cat S$, whose objects are submersions, and a diagram
\[
\begin{tikzcd}[column sep=large, row sep=large]
\mathbf{OpenErg}\ar[d, "{\mathrm{collapse}\circ T^*}"'] &
\cat{R}\ar[l, "{\mathrm{wide}}"']\ar[r, "{\mathrm{ff}}"]\ar[d] &
\potlens\ar[d, "\Phi_{\conf}"]\\
\mathbf{COrg} &
\cat{S}\ar[l, "{\mathrm{wide}}"]\ar[r] &
\org
\end{tikzcd}
\]
where the middle vertical functor sends $M$ to the submersion $T^*M\surj M$, and the lower right functor sends a submersion $p\colon E\surj B$ to the polynomial $\sum_{b:B}\yon^{E_b}$.
\end{proposition*}
On morphisms of $\cat R$, the middle vertical functor uses $\sharp_V$ to turn the parameter covector in $dE+(Tw)^*(\eta)$ into the Euler update.

\section{Notational conventions}\label{sec.prelim}
%--------------------------------------------------------------------

We fix some typographic conventions. A generic category is written in calligraphic script, $\cat{C},\cat{M},\cat{A}$, and a specifically-named category in boldface, $\Cat{Set},\Cat{Poly},\Cat{Mfd}$. A function or operation is written in roman, $\fun{ev},\fun{pr}$, and a named functor is written in sans-serif, $\Fun{T},\Fun{Box}$. Number systems use blackboard bold, $\nn,\rr$; the dynamic algebra bicategory is denoted $\org$. 

We write $\blank$ for a ``blank'' placeholder argument in expressions, e.g.\ $\rr\times\blank\colon\mfd\to\mfd$ for the product-with-$\rr$ functor. If a set has a unique element, we often denote it $!$, e.g.\ $!\colon \emptyset\to A$. We write $\inc$ for any inclusion functor that is clear from its domain and codomain categories.

We reserve $\eta$ and $\mu$ for monad units and multiplications, and $\varepsilon$ and $\delta$ for comonoid counits and comultiplications. Since $\eta$ is also the usual notation for a learning rate, we write learning rates as $\eta_{\mathrm{LR}}$.

We sometimes refer to a $(2,1)$-category simply as a category. More precisely, its homs are groupoids and composition is associative and unital up to coherent isomorphism.

By \emph{operad} we mean \emph{colored operad} unless otherwise stated. We sometimes elide the difference between monoidal categories $(\cat{C},I,\otimes)$ and their underlying operads $\cat{O}_{\cat{C}}$ with $K$-ary morphisms $c_1\otimes\cdots\otimes c_K\to c'$. Morphisms between underlying operads correspond exactly to lax morphisms between the monoidal categories.%
\footnote{That is, the functor $\Cat{SMC}_{\tn{lax}}\to\Cat{Opd}$ is fully faithful.}

\section{Smooth manifolds}\label{sec.manifolds_notation}
%--------------------------------------------------------------------

In this section we fix the differential-geometric notation used throughout.

We work in the cartesian category $(\mfd,\rr^0,\times)$ of finite-dimensional smooth real manifolds and smooth maps. For a manifold $M$ and point $m\colon\rr^0\to M$, write $T_mM$ for the tangent space at $m$ and $TM$ for the tangent bundle; write $T^*_mM$ and $T^*M$ for the cotangent space at $m$ and the cotangent bundle.

The tangent functor $T\colon\mfd\to\mfd$ preserves products, so $T(M\times N)\cong TM\times TN$; in particular
\begin{equation}\label{eqn.T_products}
T_{(m,n)}(M\times N)\cong T_mM\oplus T_nN
\qqand
T^*_{(m,n)}(M\times N)\cong T^*_mM\oplus T^*_nN.
\end{equation}

For a smooth map $f\colon M\to N$, write
\[
Tf\colon TM\to TN
\]
for the \emph{tangent map} (also called the \emph{global differential}), and
\[
T_m f\colon T_mM\to T_{f(m)}N
\qqand
(T_m f)^\top\colon T^*_{f(m)}N\to T^*_mM
\]
for the \emph{differential at $m$}---the restriction of $Tf$ to the fiber over $m\in M$---and its transpose.%
\footnote{In the literature, what we denote $T_m f$ is often denoted $Df_m$.}

We often elide the inclusion $\vect\to\mfd$, treating finite-dimensional real vector spaces as manifolds. The direct sum $(0,\oplus)$ structure in $\vect$ is (a coproduct and) a product, and the inclusion is product preserving. By standard manifold theory, the canonical global chart on a finite-dimensional real vector space $V$ provides linear isomorphisms
\begin{equation}\label{eqn.tangent_vec}
T_xV \;\cong\; V \qqand T^*_xV \;\cong\; V^*
\end{equation}
at every point $x\in V$; we use these identifications throughout, often without comment. We also will make frequent use of the canonical identification
\begin{equation}\label{eqn.canonical_dual_sum}
(V\oplus V^*)^*\cong V^*\oplus V,\qquad
\lambda\leftrightarrow(\xi,x)\quad\text{where}\quad
\lambda(x',\xi')=\xi(x')+\xi'(x).
\end{equation}

When the codomain is $\rr$, the tangent map of $U\colon M\to\rr$ can be combined with the standard constant covector field $r\mapsto +1$ on $\rr$ to give a covector field on $M$, also called the \emph{differential} of $U$:
\begin{equation}\label{eqn.differential}
dU\colon M\to T^*M,\qquad dU|_m\coloneqq(T_m U)^\top(+1)\in T^*_mM.
\end{equation}
That is, $dU|_m$ is the covector at $m$ whose pairing with a tangent vector $\dot m\in T_mM$ is $+1((T_m U)(\dot m))\in\rr$. We may regard $dU|_x$ as an element of $V^*$ under \eqref{eqn.tangent_vec}.

\section{Polynomial functors, comonads, and coalgebras}\label{sec.poly_dynamic_bg}
%--------------------------------------------------------------------

\subsection{The symmetric monoidal closed category \texorpdfstring{$\poly$}{Poly}}\label{sec.poly}

We briefly review the category $\poly$ of polynomial functors; see~\cite{niu2025polynomial} for a comprehensive treatment.

The category $\poly$ of \emph{polynomial functors} is the full subcategory of all endofunctors $p\colon\smset\to\smset$ spanned by those of the form $\sum_{i: I}\yon^{A_i}$, where $I$ is the set of \emph{positions} and $A_i$ is the set of \emph{directions} at position $i$. Since $p(1)=\sum_{i:I}1=I$, we use the compact notation $p(1)$ for the position set and $p[i]\coloneqq A_i$ for the direction set at $i: p(1)$, so that
\begin{equation}\label{eqn.poly}
p=\sum_{i: p(1)}\yon^{p[i]}=\sum_{i: p(1)}\;\prod_{d: p[i]}\yon.
\end{equation}
We use juxtaposition for scalar multiplication: $pq\coloneqq p\times q$, and we write $1=\yon^0$. A \emph{monomial} is a polynomial of the form $M\yon^N=\sum_{m\in M}\yon^N$; we refer to $\yon^N$ as a \emph{representable} and to $M=M\yon^0$ as a \emph{constant}.

One can derive from the universal property of coproducts and the Yoneda lemma that natural transformations $\varphi\colon p\to q$ are given by:
\begin{equation}\label{eqn.poly_map}
\poly(p,q)=\prod_{i: p(1)}\;\sum_{j: q(1)}\;\prod_{e: q[j]}\; \sum_{d: p[i]}1.
\end{equation}
The outer $\prod_i\sum_j$ yields a ``forward on-positions'' function $\varphi_1\colon p(1)\to q(1)$, which is the component of $\varphi$ at $1:\smset$, and the inner $\prod_e\sum_d$ yields, for each $i:p(1)$, a ``backward on-directions'' function from the directions of $q$ at $\varphi_1(i)$ to the directions of $p$ at $i$; we denote it as follows:%
\footnote{What we denote here by $\bk{\varphi}{i}$ is often denoted $\varphi^\sharp_i$; we use different notation because $\sharp$ is used throughout the paper.}
\[\bk{\varphi}{i}\colon q[\varphi_1(i)]\to p[i].\]

For polynomials $p,q:\poly$, their \emph{Dirichlet product} is
\begin{equation}\label{eqn.dirichlet}
p\otimes q\coloneqq\sum_{(i,j):p(1)\times q(1)}\yon^{p[i]\times q[j]}\;.
\end{equation}
Together with unit $\yon=\yon^1$, the Dirichlet product forms a symmetric monoidal structure, which is also closed: the \emph{internal hom} is
\begin{equation}\label{eqn.dirichlet_hom}
\ihom{p,q}=\prod_{i: p(1)}\;\sum_{j: q(1)}\;\prod_{e: q[j]}\;\sum_{d: p[i]}\yon
\end{equation}
satisfying $\poly(r\otimes p,\, q)\cong\poly(r,\,\ihom{p,q})$ naturally in $r$. Note that $\ihom{p,q}(1)=\poly(p,q)$, as is immediate from comparing \eqref{eqn.dirichlet_hom} with \eqref{eqn.poly_map}. We can rewrite it as
\begin{equation}\label{eqn.ihom_pos_dir}
\ihom{p,q}\cong\sum_{\varphi: \poly(p,q)}\yon^{\sum_{i: p(1)}q[\varphi_1(i)]}
\end{equation}

\subsection{Polynomial comonads as categories}\label{sec.comonads}

The \emph{substitution} (or \emph{composition}) \emph{product} on $\poly$ is defined by $(p\tri q)(S)\coloneqq p(q(S))$; it is a (nonsymmetric) monoidal structure with unit $\yon$. Using the expanded form of \eqref{eqn.poly}:
\begin{align}\label{eqn.substitution}
p\tri q&=
\sum_{i: p(1)}\;\prod_{d: p[i]}\;\sum_{j: q(1)}\;\prod_{e: q[j]}\yon\\\nonumber&\cong
\sum_{i:p(1)}\;\sum_{j\colon p[i]\to q(1)}\prod_{d:p[i]}\prod_{e:q[j(d)]}\yon.
\end{align}
A position of $p\tri q$ is a pair $(i,j)$ where $i: p(1)$ and $j\colon p[i]\to q(1)$; the direction set is $(p\tri q)[(i,j)]=\sum_{d:p[i]}q[j_d]$. In particular, viewing a set $S:\smset$ as the constant polynomial $S\yon^0$, substitution recovers evaluation: $p\tri S=p(S)$.

A \emph{$\tri$-comonoid} in $\poly$ is a comonoid for the substitution product: a polynomial $c$ equipped with a counit $\varepsilon\colon c\to\yon$ and comultiplication $\delta\colon c\to c\tri c$ satisfying coassociativity and counitality. Since the substitution product is composition of endofunctors on $\smset$, a $\tri$-comonoid is equivalently a comonad on $\smset$ whose underlying endofunctor is polynomial; we call it a \emph{polynomial comonad}.

Polynomial comonads are---up to isomorphism---the same data as small categories. Writing $c=\sum_{i:c(1)}\yon^{c[i]}$, the positions $c(1)$ are the objects of some category $\cat{C}$, and for each object $i:c(1)$, the directions $c[i]$ are the morphisms of $\cat{C}$ with domain $i$:
\[
c[i]\coloneqq\sum_{j:c(1)}\cat{C}(i,j).
\]
The counit $\varepsilon\colon c\to\yon$ picks out an identity morphism $\id_i:c[i]$ at each object $i$. The comultiplication $\delta\colon c\to c\tri c$ assigns codomains and composition: given an object $i$ and a morphism $f:c[i]$, the on-positions component of $\delta$ returns $\cod(f):c(1)$, and given a further morphism $g:c[\cod(f)]$, the on-directions component returns the composite $f\then g:c[i]$. The comonoid laws guarantee that $\cod(\id_i)=i$, that composition is unital, that $\cod(f\then g)=\cod(g)$, and that composition is associative.

\begin{proposition}[Polynomial comonads are categories {\cite{ahman2016directed}; see also \cite{niu2025polynomial}}]\label{prop.comonads_cats}
The above correspondence defines an isomorphism between polynomial comonads and small categories.
\end{proposition}

\begin{example}[The store comonad and the pair groupoid]\label{ex.store}
For any set $S$, the monomial $S\yon^S$ arises as the store comonad from the adjunction $S\times\blank\;\dashv\;(\blank)^S$ on $\smset$, i.e.\ the comonad with underlying endofunctor $X\mapsto S\times X^S$. 

By \cref{prop.comonads_cats} this can be viewed as a category: it has object set $S$ and, for each pair $(s,t):S\times S$, exactly one morphism $s\to t$. Thus every arrow $s\to t$ is an isomorphism with inverse $t\to s$, so this is the \emph{pair groupoid} (or \emph{codiscrete category}) on $S$.
\end{example}

\subsection{Polynomial coalgebras as dynamical systems}\label{sec.coalgebras}

For a polynomial $p$, a \emph{$p$-coalgebra} is a pair $(S,\beta)$ where $S:\smset$ is a set and $\beta\colon S\to p(S)$ is a function. We call elements of $S$ states; given a state $s:S$, the map assigns a \emph{readout} position $r_s\coloneqq\beta_1(s):p(1)$ and an \emph{update} function $\bk{\beta}{s}\colon p[r_s]\to S$ sending each direction $d:p[r_s]$ to a new state $s_d$. We sometimes succinctly write the above coalgebra data as
\begin{equation}\label{eqn.coalgebra_format}
s\mapsto (r_s, d\mapsto s_d).
\end{equation}

When $p=A\yon^B$ then a $p$-coalgebra $S\to AS^B$ is equivalently a readout function $S\to A$ and an update function $S\times B\to S$, so \eqref{eqn.coalgebra_format} splits into two pieces, $s\mapsto r_s$, $(s,d\mapsto s_d)$. But in general, the type of the input direction $d$ may depend on the output $r_s\in p(1)$.

A $p$-coalgebra is thus a deterministic dynamical system whose interface is $p$: the state exposes an output in $p(1)$ and transitions in response to inputs in $p[\beta_1(s)]$, capturing Moore machines, discretized differential equations, Markov decision processes, and other mode-dependent dynamics in a single framework~\cite{niu2025polynomial}. It is a special case of the general theory of coalgebras for endofunctors; see~\cite{jacobs2017introduction} for a comprehensive treatment.

\begin{proposition}[Coalgebras as polynomial maps]\label{prop.coalg_as_poly_map}
For $p:\poly$ and $S:\smsetiso$, there is a natural bijection
\[
\smset(S,\,p\tri S)\;\cong\;\poly(S\yon^S,\,p).
\]
\end{proposition}

\begin{proof}
A coalgebra $\beta\colon S\to p\tri S$ unpacks as a pair $\beta=(\beta_1,\beta^\sharp)\colon S\to\sum_{i:p(1)}\prod_{d:p[i]}S$: for each $s:S$, a position $\beta_1(s):p(1)$ and an update $\beta^\sharp_s\colon p[\beta_1(s)]\to S$. A polynomial map $\hat\beta\colon S\yon^S\to p$ unpacks as a pair $(\hat\beta_1,\hat\beta^\sharp)$ of identical signature by \eqref{eqn.poly_map}. The bijection sets $\hat\beta_1\coloneqq\beta_1$ and $\hat\beta^\sharp\coloneqq\beta^\sharp$.\footnote{
Equivalently, $\poly$ has a left Kan operation $\lens{p}{q}$ with $\poly(p,q'\tri q)\cong\poly(\lens{p}{q},q')$ given by $\lens{p}{q}=\sum_{i:p(1)}\yon^{q\tri p[i]}$, so $\lens{S}{S}=S\yon^S$.
}

Naturality in $p:\poly$ is just composition. For naturality in $S$, a bijection $f\colon S\To{\cong}T$ acts as $f\yon^{f\inv}\colon S\yon^S\to T\yon^T$ (positions $f$, directions $f\inv$), and we need to check
\[
\begin{tikzcd}
	S\ar[r,"\beta"]\ar[d, "f"']&p\tri S\ar[d, "p\tri f"]\\
	T\ar[r,"\beta'"']&p\tri T
\end{tikzcd}
\quad\leftrightsquigarrow\quad
\begin{tikzcd}
	S\yon^S\ar[r,"\hat\beta"]\ar[d, "f\yon^{f\inv}"']&
	p\ar[d, equal]\\
	T\yon^T\ar[r,"\hat{\beta'}"']&
	p
\end{tikzcd}
\]
The first commutes iff $\beta'_1\circ f=\beta_1$ and $f\circ\beta^\sharp_s=\beta'^\sharp_{f(s)}$ for all $s:S$; the second iff $\hat{\beta'}_1\circ f=\hat\beta_1$ and $\hat\beta^\sharp_s=f\inv\circ\hat{\beta'}^\sharp_{f(s)}$. Under the bijection $\hat\beta_\bullet=\beta_\bullet$, these coincide ($f$ being a bijection).\qedhere
\end{proof}

The Dirichlet product formula \eqref{eqn.dirichlet} gives $1\yon^1=\yon$ and $S\yon^S\otimes T\yon^T=(S\times T)\yon^{S\times T}$, so the assignment $S\mapsto S\yon^S$ extends to a strong symmetric monoidal functor $\smsetiso\to\poly$, sending a bijection $f\colon S\To{\cong}T$ to $f\yon^{f\inv}$ (\cref{prop.coalg_as_poly_map}). Composing with the Dirichlet product gives a strong monoidal action of $\smsetiso$ on $\poly$.

\begin{definition}[$\Store$ and the store action]\label{def.store_action}
Write
\[
\Store\colon(\smsetiso,1,\times)\to(\poly,\yon,\otimes),\qquad S\longmapsto S\yon^S
\]
for the above functor, and define the \emph{store action} by
\[
(\cdot)\colon\smsetiso\times\poly\to\poly
\where
S\cdot p\coloneqq S\yon^S\otimes p.
\]
\end{definition}


\subsection{Cotangent bundles as polynomials}\label{sec.cot}

The category of smooth manifolds provides the source of polynomials relevant to physics and learning. Each manifold has a cotangent bundle, and each smooth map has a transpose on cotangent fibers; combining these gives a functor into $\poly$.

\begin{definition}[Cotangent functor]\label{def.cot}
The \emph{cotangent functor} $\cot\colon\mfd\to\poly$ sends a smooth manifold $M$ to
\begin{equation}\label{eqn.cot_def}
\cot{M}\coloneqq\sum_{m\in M}\yon^{T^*_mM}
\end{equation}
where $T^*_mM$ is the cotangent space at $m$. A smooth map $f\colon M\to N$ is sent to the $\poly$ map $\cot{f}\colon\cot{M}\to\cot{N}$ whose positions and directions are
\[
  \cot{f}_1\coloneqq f
  \qqand
  \bk{\cot{f}}{m}\coloneqq(T_m f)^\top
 \]
 as maps $M\to N$ and $T^*_{f(m)}N\to T^*_mM$.
\end{definition}

This is indeed functorial: the identity map $\id_M\colon M\to M$ has $T_m(\id_M)=\id_{T_mM}$, whose transpose is $\id_{T^*_mM}$, so $\cot{\id_M}=\id_{\cot{M}}$. For composable smooth maps $f\colon M\to N$ and $g\colon N\to P$, the chain rule gives $T_m(g\circ f)=T_{f(m)}g\circ T_m f$, so
\[
(T_m(g\circ f))^\top=(T_m f)^\top\circ(T_{f(m)}g)^\top=\bk{\cot{f}}{m}\circ\bk{\cot{g}}{f(m)},
\]
which is the backward part of $\cot{f}\then\cot{g}$.

\begin{proposition}\label{prop.cot_monoidal}
The cotangent functor $\cot\colon(\mfd,\mathbb{R}^0,\times)\to(\poly,\yon,\otimes)$ is strong symmetric monoidal:
\[
\cot{\mathbb{R}^0}\cong\yon
\qqand
\cot{M\times N}\cong\cot{M}\otimes\cot{N}.
\]
\end{proposition}

\begin{proof}
The one-point manifold $\rr^0=\{0\}$ has $T^*_0\rr^0=\{0\}$, so $\cot{\mathbb{R}^0}=\sum_{\{0\}}\yon^{\{0\}}\cong\yon$, so the unit is preserved. Products are preserved by \eqref{eqn.T_products}, so we have
\begin{equation}\label{eqn.cot_times}
\cot{M\times N}=\sum_{(m,n)\in M\times N}\yon^{T^*_{(m,n)}(M\times N)}\cong\sum_{m\in M}\yon^{T^*_mM}\otimes\sum_{n\in N}\yon^{T^*_nN}=\cot{M}\otimes\cot{N}
\end{equation}
using the definition of the Dirichlet product \eqref{eqn.dirichlet}.

This isomorphism $\cot{M\times N}\cong\cot{M}\otimes\cot{N}$ is natural: given a product map $f\times g\colon M\times N\to M'\times N'$, the tangent map is block-diagonal: $T_{(m,n)}(f\times g)=T_m f\oplus T_n g$. Hence $(T_{(m,n)}(f\times g))^\top=(T_m f)^\top\times(T_n g)^\top$.
%
%\textit{Coherence.} The associator and unitor for the Dirichlet product correspond to the canonical isomorphisms $(M\times N)\times P\cong M\times(N\times P)$ and $M\times 1\cong M$ in $\mfd$, so the coherence diagrams for a strong monoidal functor commute.
\end{proof}

\begin{remark}
In fact, $\cot$ also preserves coproducts,
\[
\cot{M}+\cot{N}\cong\cot{M+N}.
\]
Hence $\cot\colon(\mfd,0,+,1,\times)\to(\poly,0,+,\yon,\otimes)$ is a distributive monoidal functor. We will not use this fact in this paper.
\end{remark}

\Cref{prop.cot_monoidal} uses only the underlying sets of the cotangent fibers, e.g.\ in \eqref{eqn.cot_times}. The linear structure is not lost, however: \cref{lem.cot_comonoid} shows that the diagonal and terminal maps in $\mfd$ induce fiberwise addition and zero on $\cot{M}$.

\begin{lemma}\label{lem.cot_comonoid}
For any smooth manifold $M$, the polynomial $\cot{M}$ is a cocommutative comonoid in $(\poly,\yon,\otimes)$. The comultiplication and counit
\[
\cot{\Delta_M}\colon\cot{M}\to\cot{M}\otimes\cot{M}
\qqand
 \cot{!_M}\colon\cot{M}\to\yon
\]
send positions by $m\mapsto(m,m)$ and $m\mapsto *$, respectively. On directions, each cotangent fiber $T^*_mM$ carries the induced cocommutative comonoid structure
\[
T^*_mM\times T^*_mM\to T^*_mM,\quad (\xi,\xi')\mapsto\xi+\xi'
\qqand 1\to T^*_mM,\quad *\mapsto 0,
\]
i.e.\ fiberwise addition and zero. Thus the $\otimes$-comonoid structure on $\cot{M}$ recovers the additive structure of each cotangent space.%
%\footnote{
%One can recover scalar structure on $T^*_mM$ as well. For any $M:\mfd$, there is a natural map
%\[
%(\cdot)\colon\cot{M}\to\yon^\rr\otimes\cot{M}
%\]
%Axioms relating the comonoid structure of $\cot{M}$ and various structures on $\rr$ enforce that the forward map is $x\mapsto (!,x)$ and that the backwards map $\bk{(\cdot)}{x}\colon (r,\xi)\mapsto r\cdot\xi$ encodes the following laws:
%\[
%	1\cdot\xi=\xi,\qquad
%	(r_1r_2)\cdot\xi=r_1\cdot(r_2\cdot\xi),\qquad
%	0\cdot\xi=0,\qand
%	r\cdot(\xi_1+\xi_2)=(r\cdot\xi_1)+(r\cdot\xi_2).
%\]
%Notably missing is the axiom $(r_1+r_2)\cdot\xi=(r_1\cdot\xi)+(r_2\cdot\xi)$, which seemingly cannot be encoded this way because there is seemingly no way to copy a cotangent vector ($\xi$).
%}
\end{lemma}

\begin{proof}
Since $(\mfd,\mathbb{R}^0,\times)$ is cartesian, every manifold $M$ is a cocommutative comonoid via the diagonal $\Delta_M\colon M\to M\times M$ and $!_M\colon M\to\mathbb{R}^0$. Since $\cot$ is strong symmetric monoidal (\cref{prop.cot_monoidal}), it preserves comonoid structures. On positions this gives $m\mapsto(m,m)$ and $m\mapsto *$. For the backward maps: $T_m\Delta_M$ is the diagonal $T_mM\to T_mM\times T_mM$, $v\mapsto(v,v)$; its transpose is addition $T^*_mM\times T^*_mM\to T^*_mM$. The map $T_m(!_M)$ is $T_mM\to 0$, whose transpose is the map $1\to T^*_mM$ that selects the zero covector.
\end{proof}


\begin{proposition}[Hopf monoid structure on cotangent bundles of Lie groups]\label{prop.cot_hopf}
Let $G$ be a Lie group with unit $\eta\colon\mathbb{R}^0\to G$, multiplication $\mu\colon G\times G\to G$, and inversion $\iota\colon G\to G$. Then $\cot{G}$ is a Hopf monoid in $(\poly,\yon,\otimes)$: the monoid structure is
\[
\cot{\eta}\colon\yon\to\cot{G},\qquad \cot{\mu}\colon\cot{G}\otimes\cot{G}\to\cot{G},
\]
the comonoid structure is as in \cref{lem.cot_comonoid}, and the antipode is $\cot{\iota}\colon\cot{G}\to\cot{G}$.
\end{proposition}

\begin{proof}
It is well known that strong monoidal functors preserve monoids, comonoids, and bimonoids: they preserve both the defining maps and the axioms relating them. For the same reason they also preserve the antipode structure and axioms, hence the Hopf monoid structure. See also~\cite{spivak2023hopf}.
\end{proof}

\begin{remark}\label{rem.cot_as_category}
It turns out that $\cot{M}$ is sometimes not only a $\otimes$-comonoid but also a $\tri$-comonoid, i.e.\ a category by \cref{prop.comonads_cats}. In these cases, the cotangent vectors $\xi\in T^*_mM$ can be thought of as maps out of $m$, in the sense that they exponentiate via \eqref{eqn.flow_cot} to give paths that land at other objects. We conjecture (see \cref{rmk.rnla_generalization}) that this works for any reactive nilpotent Lie algebra: the Baker-Campbell-Hausdorff formula \cite{knapp2002lie} allows one to compose cotangent vectors like morphisms. For simplicity, we only work with reactive vector spaces in this paper; the nilpotent Lie-algebra version is left for future work.
\end{remark}

Each such $\cat{W}$ is a \emph{composition syntax}: its multimorphisms specify legal arrangements of boxes---how systems compose---with no commitment about what fills them. An algebra is a semantics. A variety of examples of these wiring-diagram operads, whose algebras are structured categories, can be found in the literature. \cite{Spivak.Schultz.Rupel:2016a} treats the traced and compact cases, showing in particular that the operad $\cat{W}_{\tn{TrCat}}$ for traced categories is the operad $1\tn{-}\Cat{Cob}$ of oriented 1-dimensional cobordisms. \cite{fong2019hypergraph} treats hypergraph categories, whose associated operad $\cat{W}_{\tn{HypCat}}$ is given by cospans of finite sets. The symmetric monoidal case~\cite{patterson2021wiring} is in some sense the most basic of the three, but its operad $\cat{W}_{\tn{MnCat}}$ is less easy to describe directly.

An advantage of the operadic perspective is that it allows us to more uniformly treat various sorts of category, including ones that may not have an existing name. For example, 
consider the notion of ``traced monoidal categories without identity''; one might balk at this because they wouldn't know whether the ``yanking'' axiom could so easily just be discarded. But as an operad it is fine: it is the suboperad comprising the left class of a certain factorization system on $1\tn{-}\Cat{Cob}$.

Another advantage is that wiring diagram algebras also easily represent $\cat{V}$-enriched categories for monoidal categories $\cat{V}$, namely by using algebras $\cat{W}\to\cat{V}$ valued in $\cat{V}$ in place of \eqref{eqn.W_alg}. For example, a $\vect$-enriched category with object set $O$ is an operad functor $\cat{W}_{O\tn{-Cat}}\to\vect$.


One can build \emph{dynamic} versions of the structures in \eqref{eqn.wd_examples}, in which the ``fillers'' of a box are ``morphisms that change in time'', i.e.\ coalgebras. In \cite{shapiro2022dynamic}, a dynamic category is defined to be a category enriched in $\org$; similarly for dynamic monoidal categories or dynamic operads. Given the ideas above, these are just operad functors
\[
\cat{W}_{O\tn{-Cat}}\to\org
\qquad
\cat{W}_{O\tn{-MnCat}}\to\org
\qquad
\cat{W}_{O\tn{-Opd}}\to\org
\] 
for any $O:\smset$. We continue with this approach, and as such need to recall $\org$. We do so in \cref{sec.org}. In \cref{sec.W_choice} we will choose the particular composition syntax $\cat{W}$ used in this paper.

\subsection{The monoidal bicategory \texorpdfstring{$\org$}{Org}}\label{sec.org}

We recall the monoidal bicategory $\org$ from~\cite{spivak2021learners}; see also~\cite{shapiro2022dynamic}. The objects of $\org$ are polynomials, and for polynomials $p,q$ the hom-category is
\[\org(p,q)\coloneqq\ihom{p,q}\tn{-}\Cat{Coalg}.\]
Its monoidal structure $(\yon,\otimes)$ is induced by the Dirichlet product on polynomials. A morphism $p\to q$ in $\org$ is an $\ihom{p,q}$-coalgebra $(S,\,\beta\colon S\to\ihom{p,q}\tri S)$. The interpretation is interactional: $p$ is an \emph{internal} interface and $q$ is an \emph{external} one, and at each state $s\in S$ the coalgebra converts each internal output $i\in p(1)$ into an external output $j\in q(1)$, then converts each external input $e\in q[j]$ into an internal input $d\in p[i]$ together with a new state $s'\in S$. We often elide the difference between $\org$ as a monoidal bicategory and $\org$ as a category-enriched operad, with maps
\[
\org(p_1,\ldots,p_K,q)=[p_1\otimes\cdots\otimes p_K,q]\coalg.
\]
These better point to the intended semantics---internal interfaces $p_1,\ldots,p_K$ within a larger external interface $q$---but the notation is heavier.

The category $\ihom{p,q}\coalg$ has as objects pairs $(S,\beta)$ where $S$ is a set and $\beta\colon S\to\ihom{p,q}\tri S$ is a function, and where a morphism from $(S,\beta)$ to $(S',\beta')$ is a function $f\colon S\to S'$ such that $(\ihom{p,q}\tri f)\circ\beta=\beta'\circ f$. We refer to $S$ as the \emph{state set}.

Unwinding the definition of a $[p,q]$-coalgebra $(S,\beta)$ using \eqref{eqn.dirichlet_hom}, every state $s:S$ is sent to an element of
\[
[p,q](S)=\prod_{i:p(1)}\sum_{j:q(1)}\prod_{e:q[j]}\sum_{d:p[i]}S,
\]
i.e.\ for each output $i:p(1)$ of the internal box $p$, an assigned output $j(s,i):q(1)$ of the external box, and for every input $e:q[j]$ of the external box, an assigned input $d(s,i,e):p[i]$ of the internal box, together with a new state $s'(s,i,e):S$. We can denote such a function $\beta$ concisely in the form
\begin{equation}\label{eqn.coalgebra_concise}
s\;\mapsto\;i\;\mapsto\;\Bigl(j(s,i),\;e\mapsto\bigl(d(s,i,e),s'(s,i,e)\bigr)\Bigr).
\end{equation}


\begin{proposition}[\cite{spivak2021learners,shapiro2022dynamic}]\label{prop.org}
The hom-categories $\ihom{p,q}\coalg$ assemble into a monoidal bicategory $\org$ with polynomials as objects, with monoidal structure induced by the Dirichlet product on polynomials.
\end{proposition}

This structure arises from the fact that the functor $\blank\coalg$ from $(\poly,\yon,\otimes)$ to $(\smcat,1,\times)$ is lax monoidal:
\[
1\to\yon\coalg
\qqand
p\coalg\times q\coalg\to(p\otimes q)\coalg.
\]
Thus the structure maps $\yon\to[p,p]$ and $[p,q]\otimes[q,r]\to[p,r]$ induce the identity and composition functors
\[
1\to[p,p]\coalg
\qqand
[p,q]\coalg\times[q,r]\coalg\to[p,r]\coalg.
\]

\begin{remark}[$\org$ is monoidal closed]\label{rmk.org_closed}
The polynomial $[p,q]$ also serves as the internal hom in $\org$:
\[
\org(a,[p,q])\,=\,[a,[p,q]]\coalg\;\cong\;[a\otimes p,q]\coalg\,=\,\org(a\otimes p,q),
\]
by closedness of $\poly$ (\cref{sec.poly}). In particular, every 1-morphism $f\colon p\to q$ in $\org$ corresponds to a 0-morphism $\bar f\colon\yon\to[p,q]$.
\end{remark}

\subsection{The Para construction}\label{sec.para_general}

We use the following form of the Para construction. If a symmetric monoidal category $\cat{A}$ acts on a category $\cat{D}$, the category $\para{\cat{A}}{\cat{D}}$ has the same objects as $\cat{D}$, and a morphism $x\to y$  in $\para{\cat{A}}{\cat{D}}$ is a pair $(a,f)$ with $a:\cat{A}$ and
\[
f\colon a\cdot x\to y
\]
in $\cat{D}$. We call such morphisms \emph{parameterized maps} in $\cat D$. The identity on $x$ has parameter $I$ and action given by the unitor $I\cdot x\cong x$. The composite of $(a,f)\colon x\to y$ and $(b,g)\colon y\to z$ has parameter $b\otimes a$ and uses
\begin{equation}\label{eqn.para_map}
(b\otimes a)\cdot x\cong b\cdot(a\cdot x)\To{b\cdot f}b\cdot y\To{g}z.
\end{equation}

When $\cat A$ and $\cat D$ are both symmetric monoidal and the action is monoidal, $\para{\cat A}{\cat D}$ inherits a symmetric monoidal structure: on objects, $x\otimes y$ is the $\cat D$-tensor, and the tensor of $(a,f)\colon x\to y$ and $(b,g)\colon x'\to y'$ has parameter $a\otimes b$ and underlying map
\begin{equation}\label{eqn.para_tensor}
(a\otimes b)\cdot(x\otimes x')\To{\cong}(a\cdot x)\otimes(b\cdot x')\To{f\otimes g}y\otimes y',
\end{equation}
where the first isomorphism comes from the action being monoidal.

The Para construction extends to a bicategory: a 2-cell $(a,f)\Rightarrow(a',f')$ in $\para{\cat A}{\cat D}(x,y)$ is a morphism $\alpha\colon a\to a'$ in $\cat A$ such that $f'\circ(\alpha\cdot x)=f$. When $\cat A$ is a groupoid, all 2-cells are invertible, and each hom-category $\para{\cat A}{\cat D}(x,y)$ is a groupoid.
In the cases below, the parameter categories are groupoids, so these Para constructions are naturally $(2,1)$-categories; by the convention of \cref{sec.prelim}, we will usually call them categories.

The following is straightforward.

\begin{proposition}[Para by strong monoidal functors]\label{prop.para_strong_induced}
A strong monoidal functor $J\colon\cat{A}\to\cat{D}$ induces an action of $\cat{A}$ on $\cat{D}$ by left multiplication, and a monoidal natural transformation $\theta\colon J'\circ F\Rightarrow G\circ J$ as on the left, with $F,J,J'$ strong monoidal and $G$ lax (resp.\ strong) monoidal, induces a lax (resp.\ strong) monoidal action square as on the right:
\[
\begin{tikzcd}[ampersand replacement=\&]
\cat A\ar[r,"J"]\ar[d,"F"', ""{name=left}]\& \cat D\ar[d,"G", ""' {name=right}]\\
\cat A'\ar[r,"J'"']\& \cat D'
\arrow[Rightarrow, from=left, to=right, shorten <=3mm, shorten >=3mm, "\theta"]
\end{tikzcd}
\quad\leadsto\quad
\begin{tikzcd}[ampersand replacement=\&]
\cat A\times\cat D\ar[r,"(\cdot)"]\ar[d,"F\times G"', ""{name=left}]\& \cat D\ar[d,"G", ""' {name=right}]\\
\cat A'\times\cat D'\ar[r,"(\cdot')"']\& \cat D'.
\arrow[Rightarrow, from=left, to=right, shorten <=6mm, shorten >=6mm]
\end{tikzcd}
\]
\end{proposition}

\begin{proposition}[Para functoriality from action squares {\cite[\S 3.6, eq.~(3.59)]{capucci2024actegories}}]\label{prop.para_square}
Suppose $\cat A,\cat A'$ are symmetric monoidal categories acting on $\cat D,\cat D'$, that $F\colon\cat A\to\cat A'$ is a strong monoidal functor, $G\colon\cat D\to\cat D'$ is a functor, and $\theta\colon F(a)\cdot G(x)\to G(a\cdot x)$ is a natural transformation compatible with the action unitors and associators:
\begin{equation}\label{eqn.para_square}
\begin{tikzcd}[ampersand replacement=\&]
\cat A\times\cat D\ar[r,"(\cdot)"]\ar[d,"F\times G"', ""{name=left}]\& \cat D\ar[d,"G", ""' {name=right}]\\
\cat A'\times\cat D'\ar[r,"(\cdot')"']\& \cat D'.
\arrow[Rightarrow, from=left, to=right, shorten <=6mm, shorten >=6mm, "\theta"]
\end{tikzcd}
\end{equation}
Then there is an induced functor
\[
\para{F}{G}\colon\para{\cat A}{\cat D}\;\longrightarrow\;\para{\cat A'}{\cat D'}.
\]
When $\cat D,\cat D'$ are symmetric monoidal, the actions are monoidal, $G$ is strong (resp.\ normal lax, resp.\ lax) symmetric monoidal, and $\theta$ is monoidal, then $\para{F}{G}$ extends to a strong (resp.\ normal lax, resp.\ lax) monoidal functor.
\end{proposition}

\begin{proof}
The hypothesis is a 1-cell in the 2-category $\Cat{Act}$ of actegories \cite[\S 3.6, eq.~(3.59)]{capucci2024actegories}; the induced functor records the action of $\mathbb{P}\Cat{ara}$ on it. For the normal-lax case: the unitor of $\para{F}{G}$ at the unit object $(I_{\cat A}, I_{\cat D})$ is built from $F$'s (iso) unitor and $G$'s unitor, so iso-ness of the latter is inherited.\qedhere
\end{proof}

\subsection{Lenses}\label{sec.lenses}
We first recall the category $\Lens{\cat{C}}$ of lenses in a symmetric monoidal category $(\cat{C},I,\otimes)$; see \cite{hedges2017coherence,spivak2019generalized}. An object is a pair $\lensob{c}$ in which $\outp c$ carries a commutative comonoid structure $(\varepsilon_{\outp c},\delta_{\outp c})$. A morphism $f\colon\lensob{c}\to\lensob{d}$ consists of a pair of maps $f=\binom{\inpt f}{\outp f}$ where
\begin{equation}\label{eqn.lens_def}
\outp f\colon \outp c\to\outp d
\qqand
\inpt f\colon \outp c\otimes\inpt d\to\inpt c,
\end{equation}
and $\outp f$ is a comonoid homomorphism.%
\footnote{
When $(\cat{C},1,\times)$ is cartesian monoidal, every object has a unique comonoid structure and every morphism is automatically a comonoid homomorphism~\cite{fox1976coalgebras}.
}
Such a morphism can be depicted as follows:
\[
\begin{tikzpicture}[oriented WD, bb port length=5pt, bb port sep=1, bb min width=.4cm, bbx=.5cm, bby=.7ex, baseline=(fo)]
  \node[bb={1}{1}] (fo) {$\outp f$};
  \node[bb={1}{2}, above left=6 and 1.5 of fo] (fi) {$\inpt f$};
  \node[circle, draw, fill=black, inner sep=0, minimum size=3pt, left=1 of fo] (dot) {};
  \coordinate (co) at ($(dot)+(-3,0)$);
  \coordinate (do) at ($(fo.east)+(1,0)$);
  \coordinate (ci) at (co |- fi_in1);
  \coordinate (di) at (do |- fi_out2);
  \node[left=0 of co] {$\outp c$};
  \node[right=0 of do] {$\outp d$};
  \node[left=0 of ci] {$\inpt c$};
  \node[right=0 of di] {$\inpt d$};
  \draw[ar] (co) to (dot);
  \draw[ar] (dot) to (fo_in1);
  \draw[ar] (fo_out1) to (do);
  \draw[ar] (fi_in1) to (ci);
  \draw[ar] (di) to (fi_out2);
  \draw[ar] (dot) to[out=30, in=0] (fi_out1);
\end{tikzpicture}
\]
Morphisms compose as follows: given also $g\colon \lensob{d}\to\lensob{e}$, the composite $f\then g$ is given by
\[
\outp{(f\then g)}=\outp f\then\outp g
\qqand
\inpt{(f\then g)}=
	(\delta_{\outp{c}}\otimes\inpt{e})\then
	(\outp{c}\otimes\outp{f}\otimes\inpt{e})\then
	(\outp{c}\otimes\inpt{g})\then
	\inpt{f}.
\]
This dense notation can be depicted in a string-diagram as follows:
\begin{equation}\label{eqn.lens_pic}
\begin{tikzpicture}[oriented WD, bb port length=5pt, bb port sep=1, bb min width=.4cm, bbx=.5cm, bby=.7ex, baseline=(fo)]
  \node[bb={1}{1}] (fo) {$\outp f$};
  \node[bb={1}{1}, right=5 of fo] (go) {$\outp g$\vphantom{$\inpt f$}};

  \coordinate (co) at ($(dot1)+(-3,0)$);
  \coordinate (eo) at ($(go.east)+(1,0)$);
  \coordinate (ci) at (co |- fi_in1);
  \coordinate (ei) at (eo |- gi_out2);
  \node[left=0 of co] {$\outp c$};
  \node[right=0 of eo] {$\outp e$};
  \node[left=0 of ci] {$\inpt c$};
  \node[right=0 of ei] {$\inpt e$};
  \draw[ar] (co) to (dot1);
  \draw[ar] (dot1) to (fo_in1);
  \draw[ar] (fo_out1) to node[above, font=\scriptsize] {$\outp d$} (dot2);
  \draw[ar] (dot2) to (go_in1);
  \draw[ar] (go_out1) to (eo);
  \draw[ar] (fi_in1) to (ci);
  \draw[ar] (ei) to (gi_out2);
  \draw[ar] (gi_in1) to[out=180, in=0] node[above, font=\scriptsize] {$\inpt d$} (fi_out2);

  \draw[ar] (dot2) to[out=30, in=0] (gi_out1);
\end{tikzpicture}
\end{equation}
The identity on $\lensob{c}$ is $\binom{\varepsilon_{\outp c}\otimes\id_{\inpt c}}{\id_{\outp c}}$, i.e.\ counit in the first argument. The category $\Lens{\cat{C}}$ inherits a monoidal structure with unit $\binom{I}{I}$ and
\[
\lensob{c}\otimes\lensob{d}\coloneqq\lensobs{c}{d}.
\]

Our main example will be $\cat{C}=\mfd$ with its cartesian product. But the following is simple, instructive, and will come in handy.
\begin{example}\label{ex.lens_finsetop}
The category $\finset\op$, opposite to the category of finite sets, is cartesian monoidal where the product is given by the disjoint union $(0,+)$, i.e.\ the coproduct in $\finset$. Thus every object carries its canonical cartesian comonoid structure, and every morphism preserves it automatically. An object in $\Lens{\finset\op}$ is just a pair of finite sets $\binom{\inpt A}{\outp A}$.

A lens $\binom{\inpt f}{\outp f}\colon\binom{\inpt A}{\outp A}\to\binom{\inpt B}{\outp B}$ consists of two maps
\begin{equation}\label{eqn.lens_finsetop}
\outp A\From{\outp f} \outp B
\qqand
\outp A+\inpt B\From{\inpt f} \inpt A,
\end{equation}
with no further homomorphism condition.
\end{example}

\begin{proposition}\label{prop.lens_functoriality}
The $\Lens{-}$ construction is functorial in symmetric monoidal categories and strong monoidal functors.
\end{proposition}
\begin{proof}
If $F\colon\cat{C}\to\cat{D}$ is colax monoidal, it preserves comonoid structures, so we can define $\Lens F$ on objects. If $F$ is lax monoidal, it has a productor $F_2\colon F(A)\otimes F(B)\to F(A\otimes B)$ and we can define $\Lens F$ on morphisms: given a lens morphism $\binom{\inpt f}{\outp f}$ we set $\Lens F\binom{\inpt f}{\outp f}\coloneqq\binom{F(\inpt f)\circ F_2}{F(\outp f)}$. For functoriality the lax and colax structures must cohere, i.e. the lax structure must be inverse to the colax structure; we leave the details to the reader.
\qedhere
\end{proof}

\begin{example}
The functor $\blank\yon\colon(\smset,1,\times)\to(\poly,\yon,\otimes)$ sending $A\mapsto A\yon$ is strong monoidal: $A\yon\times B\yon\cong (A\times B)\yon$. As such it induces a strong monoidal functor
\begin{equation}\label{eqn.lens_yon}
\Lens{\blank\yon}\colon\Lens{\smset}\to\Lens{\poly}.
\end{equation}
\end{example}

\subsection{Lenses can represent serial, parallel, and feedback}\label{sec.plenspot_ops}

Recall from \cref{sec.dynamic_structures} that operads---and hence monoidal categories---can be used to encode compositional syntax. In fact, we can think of the monoidal category $\Lens{\cat{C}}$ of lenses in a symmetric monoidal category $\cat{C}$ as giving a syntax for something like ``traced symmetric monoidal semicategories'', as we now explain. This section is meant for intuition and in particular does not define the previously quoted phrase. It will also not be used in any formal development.

By a \emph{semicategory} we mean almost a category, except without the notion of identities (like a semigroup is a group without identities). So to say that $\Lens{\cat{C}}$ is a composition syntax for something like traced symmetric monoidal semicategories, we should show that it interprets diagrams that look like this. 
\begin{equation}\label{eqn.arb_wd}
\varphi\coloneqq
\begin{tikzpicture}[oriented WD, bb min width=.6cm, bb port sep=1, bbx=.6cm, bby=1ex, bb port length=2.5pt, baseline=(X2)]
  \node[bb port sep=2, bb={2}{2}] (X1) {};
  \node[bb={1}{1}, right=.7 of X1_out1] (X2) {};
  \node[bb={0}{0}, fit={(X1) (X2) ($(X1.north)+(0,2.5)$)}] (Y) {};
  \node[coordinate] at (Y.west|-X1_in2) (Y_in1) {};
  \node[coordinate] at (Y.east|-X2_out1) (Y_out1) {};
  \node[coordinate] at (Y.east|-X1_out2) (Y_out2) {};
  \draw[ar] (Y_in1) -- node[above, font=\scriptsize] {$A$} (X1_in2);
  \draw[ar] (X1_out1) -- node[above, font=\scriptsize] {$B$} (X2_in1);
  \draw[ar] (X2_out1) -- node[above, font=\scriptsize] {$C$} (Y_out1);
  \draw[ar] (X1_out2) -- node[below, font=\scriptsize] {$D$} (Y_out2);
  \draw[ar] let \p1=(X2.north east), \p2=(X1.north west), \n1={\y2+\bby}, \n2=\bbportlen in
          (X2_out1) to[in=0,in looseness=.9] (\x1+.7*\n2,\n1) -- node[above, font=\scriptsize] {$C$} (\x2-.7*\n2,\n1) to[out=180] (X1_in1);
  \end{tikzpicture}
 \end{equation}

We will consider boxes as lenses $\binom{\inpt c}{\outp c}$, where the ports on the left of the box are the input $\inpt c$ and the ports on the right of the box are the output $\outp c$. The wiring diagram itself is a morphism in $\Lens{\cat{C}}$ from the tensor product of the internal boxes to the external box.

The wiring diagram \eqref{eqn.arb_wd} has three boxes, two internal boxes and the external box, so it should be represented in $\Lens{\cat{C}}$ by a map of the form
\[
\varphi\colon\binom{C\otimes A}{B\otimes D}\otimes\binom{B}{C}\to\binom{A}{C\otimes D}
\]
where let us say that $B,C,D$ are comonoids. Unfolding, we need two maps in $\cat{C}$:
\begin{equation}\label{eqn.wd_as_maps}
B\otimes D\otimes C\to C\otimes D
\qqand
(B\otimes D\otimes C)\otimes A\to C\otimes A\otimes B
\end{equation}
But these maps are obvious: they are just counit projections and braidings.

One could take $\cat{C}\coloneqq(\mfd,\rr^0,\times)$. Then $A,B,C, D$ are manifolds (all of which are naturally comonoids) and the wiring diagram represents information flow, shuffling coordinates around. But there are many more smooth functions of the form \eqref{eqn.wd_as_maps} than there are wiring diagrams, e.g.\ there is more than one smooth function $\rr\to\rr$.

One can also interpret \eqref{eqn.arb_wd} in $\finset\op$, the opposite of the category of finite sets. Taking $A\coloneqq\{a\}$, $B\coloneqq\{b\}$, $C\coloneqq\{c\}$, and $D\coloneqq\{d\}$ all to have one element for simplicity, each has a unique comonoid structure. Now \eqref{eqn.wd_as_maps} consists of two maps
\[
\{b,d,c\}\from\{c,d\}
\qqand
\{b,d,c\}+\{a\}\from\{c,a,b\}.
\]
These two functions entirely determine the wiring diagram \eqref{eqn.arb_wd} as an operad morphism, saying how each external outgoing port $c,d$ is ``fed by'' some internal outgoing port (in $\{b,d,c\}$), and how each internal ingoing port $c,a,b$ is ``fed by'' either an internal outgoing port (in $\{b,d,c\}$) or the external ingoing port, $a$. 

Since $\finset\op$ is the free cartesian category on one object, for any cartesian category $\cat{M}$ and object $R$, there is a strong monoidal functor $R^-\colon\finset\op\to\cat{M}$. We record a special case.

\begin{lemma}\label{lemma.lens_rr}
The functor $\rr^-\colon\finset\op\to\mfd$ is strong monoidal, hence induces a strong monoidal functor
\[
\Lens{\rr^-}\colon\Lens{\finset\op}\to\Lens{\mfd}.
\]
\end{lemma}

\subsection{Backward monads on lenses}\label{sec.backwards}

We will add a notion of potentials to our lenses by proving a more general result: any strong monad on $\cat{C}$ induces a comonad on $\Lens{\cat{C}}$ by applying it to the input / backward-pass part. We pun on the word ``backwards'' to refer to the fact that it applies to the backward pass and the fact that, as such, it turns a monad into a comonad.

Recall that a monad $\Fun{T}$ on a monoidal category is \emph{strong} if there are natural maps $\sigma\colon X\otimes\Fun{T}Y\to\Fun{T}(X\otimes Y)$, satisfying four diagrams~\cite{kock1972strong}. If moreover $X$ carries a counit $\varepsilon_X\colon X\to I$, then naturality of $\sigma$ in its first argument together with the unit-coherence axiom of strength gives a \emph{counital projection} $\sigma_{X,Y}\then\Fun{T}(\varepsilon_X\otimes\id_Y)=\varepsilon_X\otimes\id_{\Fun{T}Y}$:
\begin{equation}\label{eqn.counital_projection}
\begin{tikzcd}
X\otimes\Fun{T}Y\ar[r, "\sigma_{X,Y}"]\ar[d, "\varepsilon_X\otimes\id"']&
\Fun{T}(X\otimes Y)\ar[d, "\Fun{T}(\varepsilon_X\otimes\id)"]\\
\Fun{T}Y\ar[r, equal]&
\Fun{T}Y
\end{tikzcd}
\end{equation}

When $\Fun{T}$ is a monoidal monad with components $\tau_0$ and $\tau_{X,Y}$, it is strong by defining $\sigma_{X,Y}\colon X\otimes \Fun{T}Y\to\Fun{T}(X\otimes Y)$ to be the composite
\[
X\otimes \Fun{T}Y\To{\eta_X}\Fun{T}(X)\otimes \Fun{T}(Y)\To{\tau_{X,Y}}\Fun{T}(X\otimes Y).
\]

\begin{proposition}\label{prop.backward_comonad}
Let $(\Fun{T},\eta,\mu,\sigma)$ be a strong monad on a symmetric monoidal category $(\cat{C},I,\otimes)$. Then there is a comonad $\Lens{\Fun{T}}$ on $\Lens{\cat{C}}$ sending $\lensob{c}\mapsto \binom{\Fun{T}\inpt c}{\outp c}$. We denote its coKleisli category by $\Lens{\cat{C}}^{\Fun{T}}\coloneqq(\Lens{\cat{C}})_{\Lens{\Fun T}}$. 

If moreover $\Fun{T}$ is a monoidal monad, then $\Lens{\Fun T}$ is a colax monoidal comonad, thus the coKleisli category $(\Lens{\cat{C}}^{\Fun{T}},I,\otimes)$ is naturally monoidal.
\end{proposition}
\begin{proof}
On a lens map $\binom{\inpt f}{\outp f}$ with $\inpt f\colon\outp c\otimes\inpt d\to\inpt c$, define the backward component of $\Lens{\Fun T}\binom{\inpt f}{\outp f}$ to be the following composite:
\begin{equation}\label{eqn.lens_T_morphism}
\outp c\otimes\Fun{T}\inpt d\To{\sigma}\Fun{T}(\outp c\otimes\inpt d)\To{\Fun{T}\inpt f}\Fun{T}\inpt c.
\end{equation}
The counit and comultiplication of $\Lens{\Fun{T}}$ are given on positions by the identity and on-directions by the unit and multiplication of the monad, together with the counit $\varepsilon_{\outp c}$:
\begin{equation}\label{eqn.lens_T_counit}
\outp c\otimes\inpt c\To{\varepsilon_{\outp c}\otimes\id}\inpt c\To{\eta}\Fun{T}\inpt c,
\end{equation}
\begin{equation}\label{eqn.lens_T_comult}
\outp c\otimes\Fun{T}\Fun{T}\inpt c\To{\varepsilon_{\outp c}\otimes\id}\Fun{T}\Fun{T}\inpt c\To{\mu}\Fun{T}\inpt c.
\end{equation}
We need to prove that $\Lens{\Fun{T}}$ preserves identity and composition (is a functor) and that the functor is counital and coassociative. These four axioms correspond precisely to the four axioms of a monad strength.
%The unit axiom~\cite[(1.5)]{kock1972strong} (left unitor coherence) gives preservation of identity, via $\sigma_{X,Y}\then\Fun{T}\pi_Y=\pi_{\Fun{T}Y}$. The $\eta$-coherence axiom of the strong monad gives the two counit laws. The $\mu$-coherence axiom, together with associativity of $\mu$, gives coassociativity.

We include only the least trivial here: preservation of composition. For $f\colon\lensob c\to\lensob d$ and $g\colon\lensob d\to\lensob e$, we must show that the following commutes (after appending $\Fun{T}\inpt f\colon\Fun{T}(\outp c\otimes\inpt d)\to\Fun{T}\inpt c$ on the right), suppressing identity tensor factors and applications of $\Fun T$ in the labels:
\[
\begin{tikzcd}[column sep=1.6em, row sep=3em, every label/.append style={font=\scriptsize}, font=\small, ampersand replacement=\&]
\outp c\otimes\Fun{T}\inpt e
  \ar[r, "\delta"]
  \ar[d, "\sigma"']
\& (\outp c)^{\otimes 2}\otimes\Fun{T}\inpt e
  \ar[r, "\outp f"]
  \ar[d, "\sigma"]
\&[5pt] \outp c\otimes\outp d\otimes\Fun{T}\inpt e
  \ar[r, "\sigma"]
  \ar[dr, "\sigma" description]
\& \outp c\otimes\Fun{T}(\outp d\otimes\inpt e)
  \ar[r, "\inpt g"]
  \ar[d, "\sigma"]
\& \outp c\otimes\Fun{T}\inpt d
  \ar[d, "\sigma"]
\\
\Fun{T}(\outp c\otimes\inpt e)
  \ar[r, "\delta"']
\& \Fun{T}((\outp c)^{\otimes 2}\otimes\inpt e)
  \ar[rr, "\outp f"']
\&
\& \Fun{T}(\outp c\otimes\outp d\otimes\inpt e)
  \ar[r, "\inpt g"']
\& \Fun{T}(\outp c\otimes\inpt d)
\end{tikzcd}
\]
The first two squares are naturality of $\sigma$ in its first argument, the middle triangle is the associator axiom of strength~\cite[(1.6)]{kock1972strong}, and the last square is naturality of $\sigma$ in its second argument.

When $\Fun T$ is moreover a monoidal monad, we obtain a colax monoidal structure on $\Lens{\Fun{T}}$: the counitor $\binom{\Fun T(I)}{I}\to\binom{I}{I}$ amounts to $\tau_0\colon I\to\Fun T I$ and the coproductor map $\binom{\Fun{T}(\inpt c\otimes\inpt d)}{\outp c\otimes\outp d}\to\binom{\Fun{T}(\inpt c)\otimes\Fun T(\inpt d)}{\outp c\otimes\outp d}$ amounts to $\tau_{\inpt c,\inpt d}\colon \Fun{T}(\inpt c)\otimes\Fun T(\inpt d)\to \Fun{T}(\inpt c\otimes\inpt d)$.
\end{proof}

A map in $\Lens{\cat{C}}^{\Fun{T}}$ is a map of the form $\binom{\Fun{T}\inpt c}{\outp c}\to\lensob{d}$ in $\Lens{\cat{C}}$, i.e.
\[
\outp f\colon \outp c\to\outp d
\qqand
\inpt f\colon \outp c\otimes\inpt d\to\Fun{T}\inpt c
\]
where $\outp f$ is a comonoid homomorphism.

\begin{example}[Monoidal monads on $\finset\op$]\label{ex.mms_finsetop}
Any finite set $S$ induces a functor
\[(S\times -)\colon\finset\op\to\finset\op,\]
which is strong monoidal by the usual distributive law
\[
S\times(B+C)\From{\cong}(S\times B)+(S\times C).
\]
Multiplication by $S$ constitutes a (comonad on $\finset$ and hence) a monad on $\finset\op$, easily checked to be monoidal with respect to $(0,+)$.%
\footnote{In fact the $S\times-$, for any $S:\finset$, are the only monoidal monads on $(\finset\op,0,+)$.
}

Thus it induces a comonad $\Lens{S\times-}$ on $\Lens{\finset\op}$. One may think of an element $s:S$ as a \emph{hyperparameter} that decides a sort of internal wiring. Indeed, the data of a morphism in the coKleisli category $\Lens{\finset\op}^{S\times-}$ is similar to that in \cref{eqn.lens_finsetop}, except that it includes a function $\inpt f_s\colon\outp A+\inpt B\from\inpt A$ for each $s:S$.
\end{example}

\begin{lemma}\label{lem.lens_T_functoriality}
The construction of \cref{prop.backward_comonad} is functorial in $(\cat{C},\Fun{T})$: a strong symmetric monoidal $F\colon\cat C\to\cat C'$ and strong monad morphism $\theta\colon F\circ\Fun T\Rightarrow\Fun T'\circ F$ induce
\[
\Cat{Lens}_{F,\theta}\colon\Lens{\cat C}^{\Fun T}\to\Lens{\cat C'}^{\Fun T'},\qquad
\lensob c\mapsto\binom{F(\inpt c)}{F(\outp c)},\qquad
\binom{\inpt f}{\outp f}\mapsto\binom{\theta\circ F(\inpt f)\circ F_2}{F(\outp f)},
\]
where $F_2$ is $F$'s productor. If $\Fun T,\Fun T'$ are monoidal monads and $\theta$ is a morphism of monoidal monads, $\Cat{Lens}_{F,\theta}$ is strong symmetric monoidal.
\end{lemma}

\begin{proof}
By \cref{prop.lens_functoriality}, $F$ induces $\Lens F\colon\Lens{\cat C}\to\Lens{\cat C'}$. By \cref{prop.backward_comonad}, $\Fun T$ and $\Fun T'$ induce comonads $\Lens{\Fun T}$ and $\Lens{\Fun T'}$. The monad morphism $\theta$ gives the natural transformation needed for a coKleisli functor,
\[
\gamma\colon\Lens{\Fun T'}\circ\Lens F\Rightarrow \Lens F\circ\Lens{\Fun T},
\]
whose component at $\lensob c$ has forward map $\id_{F(\outp c)}$ and backward map given by
\[
F(\outp c)\otimes F(\Fun T\inpt c)\To{\varepsilon_{F(\outp c)}\otimes\id}F(\Fun T\inpt c)\To{\theta_{\inpt c}}\Fun T'F(\inpt c).
\]

We define $\Cat{Lens}_{F,\theta}$ on objects by $F\lensob{c}\coloneqq\binom{F(\inpt{c})}{F(\outp c)}$. On morphisms, recall that
\[
\Lens{\cat C}^{\Fun T}\left(\lensob c,\lensob d\right)=\Lens{\cat C}\left(\Lens{\Fun T}\lensob c,\lensob d\right).
\]
For $f\in\Lens{\cat C}^{\Fun T}(\lensob c,\lensob d)$, define $\Cat{Lens}_{F,\theta}(f)$ to be the element of $\Lens{\cat C'}^{\Fun T'}(\Lens F\lensob c,\Lens F\lensob d)$ represented by the composite
\[
\Lens{\Fun T'}\circ\Lens F\lensob c\To{\gamma_{\lensob c}}\Lens F\circ\Lens{\Fun T}\lensob c\To{\Lens F(f)}\Lens F\lensob d.
\]
Unfolding, its backward component is
\[
F(\outp c)\otimes F(\inpt d)\To{F_2}F(\outp c\otimes\inpt d)\To{F(\inpt f)}F(\Fun T\inpt c)\To{\theta_{\inpt c}}\Fun T'F(\inpt c),
\]
and its output component is $F(\outp f)$, as claimed. The strong monad-morphism axioms for $\theta$ say exactly that $\gamma$ is compatible with the counits and comultiplications of the two comonads; hence $\Cat{Lens}_{F,\theta}$ preserves coKleisli identities and composition. 

If the monads are monoidal and $\theta$ is monoidal, the natural transformation $\gamma$ is monoidal, so $\Cat{Lens}_{F,\theta}$ is strong symmetric monoidal.\qedhere
\end{proof}

\begin{example}
For any finite set $S$ there is a monoidal monad $M\mapsto M^S$ on $\mfd$. In fact, this monad distributes under any other strong monad $\Fun T$,
\[
\Fun T(M^S)\to \Fun T(M)^S.
\]
The functor $\rr^-\colon\finset\op\to\mfd$ satisfies the conditions of \cref{lem.lens_T_functoriality}, so the functor $\Lens{\rr^-}$ from \cref{lemma.lens_rr} is strong monoidal. We will not pursue this example further in the paper.
\end{example}

The following is straightforward.

\begin{proposition}\label{prop.lens_inclusion}
Let $(\cat{C}, 1, \times)$ be a cartesian monoidal category and $\Fun{T}$ a monoidal monad on $\cat{C}$ with unit $\eta$. There is a strong symmetric monoidal functor
\begin{equation}\label{eqn.lens_inclusion}
\inc\colon\cat{C}\to\Lens{\cat{C}}^{\Fun{T}},\qquad X\mapsto\binom{1}{X},
\end{equation}
sending $f\colon X\to Y$ to the coKleisli lens with $\outp f=f$ and $\inpt f=!\then\eta_1\colon X\times 1\to 1\To{\eta_1}\Fun{T}(1)$.\end{proposition}

\begin{lemma}\label{lem.parameter_lens_action}
Let $\cat V$ and $\cat C$ be symmetric monoidal, let $\Fun T$ be a strong monad on $\cat C$, and let $J\colon\cat V\to\cat C$ be a strong monoidal functor such that each object $J(v)$ carries a commutative comonoid structure $(\delta_{J(v)},\varepsilon_{J(v)})$ in $\cat C$ and each morphism $J(u)$ is a comonoid homomorphism. Then we have an action of $\cat V$ on $\Lens{\cat C}^{\Fun T}$ given by
\[
v\cdot\lensob c\coloneqq\binom{\inpt c}{J(v)\otimes\outp c}.
\]
If moreover $\Fun T$ is a monoidal monad, this action is symmetric monoidal.
\end{lemma}

\begin{proof}
Given $f\colon\lensob c\to\lensob d$ in $\Lens{\cat C}^{\Fun T}$ and $u\colon v\to w$ in $\cat V$, set
\[
u\cdot f\coloneqq\binom{(\varepsilon_{J(v)}\otimes\outp c\otimes\inpt d)\then\inpt f}{J(u)\otimes\outp f}\colon
\binom{\inpt c}{J(v)\otimes\outp c}
\to
\binom{\inpt d}{J(w)\otimes\outp d}.
\]
{\emergencystretch=2em
Checking functoriality reduces immediately to the counital projection \eqref{eqn.counital_projection} and the comonoid-homomorphism assumption on $J$, i.e.\ that
\[
J(v)\To{J(u)}J(w)\To{\varepsilon_{J(w)}} I
\]
equals $\varepsilon_{J(v)}$.
\par}

When $\Fun T$ is monoidal, $\Lens{\cat C}^{\Fun T}$ is symmetric monoidal by \cref{prop.backward_comonad}, and the comparisons $J(I)\cong I$ and $(v\otimes w)\cdot(\lensob c\otimes\lensob d)\cong(v\cdot\lensob c)\otimes(w\cdot\lensob d)$ come directly from the strong monoidality of $J$.
\end{proof}

We call $\Theta$ the \emph{Moore internalization} functor, as justified by \cref{ex.moore}.

\begin{example}\label{ex.moore}
For the symmetric monoidal closed category $(\poly,\yon,\otimes,[-,-])$, applying $\Theta$ to lenses of the form $\binom{A\yon}{B\yon}$ yields
\[
\Theta\binom{A\yon}{B\yon}=B\yon\otimes[A\yon,\yon]\cong B\yon^A.
\]
Restricted to this full subcategory of $\Lens{\poly}$, i.e. the image of \eqref{eqn.lens_yon}, the functor $\Theta$ is fully faithful: a lens map $\binom{A\yon}{B\yon}\to\binom{A'\yon}{B'\yon}$ is a map $B\to B'$ and $B\times A'\to A$, which is exactly the data of a polynomial map $B\yon^A\to B'\yon^{A'}$.

A $B\yon^A$-coalgebra $S\to BS^A$ is equivalently a pair of functions $S\to B$, $S\times A\to S$, i.e.\ an $A$-input, $B$-output Moore machine~\cite{moore1956gedanken,niu2025polynomial}.
\end{example}

All lax monoidal functors preserve monoids, so in particular monoidal monads do.

\begin{definition}\label{def.T_monoid}
Let $(\Fun{T},\eta,\mu,\tau)$ be a monoidal monad on a symmetric monoidal category $\cat{C}$. A \emph{$\Fun{T}$-monoid in $\cat{C}$} is a $\otimes$-monoid $(z,e_z,m_z)$ in $\cat{C}$
\[
\begin{tikzcd}[ampersand replacement=\&]
z\ar[r,"\eta_z"]\ar[dr,equal]\& \Fun{T}z\ar[d,"\alpha"]\\
\& z
\end{tikzcd}
\hspace{1in}
\begin{tikzcd}[ampersand replacement=\&]
\Fun{T}\Fun{T}z\ar[r,"\mu_z"]\ar[d,"\Fun{T}\alpha"']\& \Fun{T}z\ar[d,"\alpha"]\\
\Fun{T}z\ar[r,"\alpha"']\& z
\end{tikzcd}
\]
together with a $\Fun{T}$-algebra structure $\alpha\colon\Fun{T}z\to z$ such that $\alpha$ is a monoid homomorphism
\begin{equation}\label{eqn.T_monoid}
\begin{tikzcd}[ampersand replacement=\&]
I\ar[r,"\tau_0"]\ar[d,"e_z"']\& \Fun{T}I\ar[r,"\Fun{T}e_z"]\& \Fun{T}z\ar[d,"\alpha"]\\
z\ar[r,"\eta_z"']\& \Fun{T}z\ar[r,"\alpha"']\& z
\end{tikzcd}
\hspace{1in}
\begin{tikzcd}[ampersand replacement=\&]
\Fun{T}z\otimes\Fun{T}z\ar[r,"\tau_{z,z}"]\ar[d,"\alpha\otimes\alpha"']\& \Fun{T}(z\otimes z)\ar[r,"\Fun{T}m_z"]\& \Fun{T}z\ar[d,"\alpha"]\\
z\otimes z\ar[rr,"m_z"']\&\& z
\end{tikzcd}
\qedhere
\end{equation}
\end{definition}

\begin{remark}\label{rmk.T_monoid_EM}
A $\Fun{T}$-monoid in $\cat{C}$ is the same data as a $\otimes$-monoid in the Eilenberg--Moore category $\cat{C}^{\Fun{T}}$, equivalently a $\Fun{T}$-algebra in $\Cat{Mon}_\otimes(\cat{C})$. The two presentations agree because $\Fun{T}$ being monoidal is exactly the condition that the monoidal structure on $\cat{C}$ lifts to one on $\cat{C}^{\Fun{T}}$ (equivalently, that $\Fun{T}$ lifts to a monad on $\Cat{Mon}_\otimes(\cat{C})$); see~\cite{kock1972strong, seal2013tensors}.
\end{remark}

\subsection{Definition and canonical pairing}\label{sec.rvect_def}

We now introduce the parameter objects for the Para construction of the next section. A reactive vector space is a finite-dimensional real vector space equipped with a smooth section into self-isomorphisms of its dual---equivalently, a smoothly varying nondegenerate bilinear form. The point of carrying the form is that it turns covectors into updates, and the cotangent construction of \cref{sec.TT} supplies the phase-space version used in Hamiltonian dynamics.

\begin{definition}\label{def.rvect}
A \emph{reactive vector space} is a finite-dimensional real vector space $V$ together with a smooth section $\sharp_V\colon V\to\Iso(V^*,V)$, the \emph{sharp} map, with value $\sharp_x\colon V^*\To{\cong}V$ at $x\in V$.\footnote{The terminology follows~\cite{capucci2024organizing}, where a smooth section of $[T^*X,TX]$ over a manifold $X$ is called a \emph{reaction}; the above is the non-degenerate, vector-space case.}%
\footnote{
Equivalently, $\sharp_V$ is a smooth section of the bundle whose fiber over $x:V$ is the set $\Iso(T_x^*V,T_xV)$, under the canonical identifications $T_xV\cong V$ and $T^*_xV\cong V^*$. It will be more convenient to use the above form.
}
Its pointwise inverse $\flat_x\coloneqq\sharp_x\inv\colon V\to V^*$ is the \emph{flat} map at $x$, and the corresponding nondegenerate bilinear form on $V$, the \emph{pairing at $x$}, is
\begin{equation}\label{eqn.pairing}
\pairing{v,v'}_x\coloneqq\flat_x(v)(v')\colon V\otimes V\to\rr.
\end{equation}
The three forms $\sharp_x$, $\flat_x$, and $\pairing{-,-}_x$ package the same data; we use whichever is most convenient. The \emph{constant} case $\sharp_x=\sharp_0$ for all $x$ is the familiar setting of a single bilinear form on $V$.

We define the category $\rvect$ to have reactive vector spaces as objects, and as morphisms $(V,\sharp_V)\to(W,\sharp_W)$ the linear isomorphisms $\phi\colon V\To{\cong}W$ preserving the pairing pointwise: $\pairing{\phi v,\phi v'}_{\phi(x)}=\pairing{v,v'}_x$ for all $x,v,v'\in V$.%
\footnote{
Restricting to isomorphisms (making $\rvect$ a groupoid) is essential for our development below: each $\rvect$-morphism is used both as $\phi$ on vectors and as $(\phi^*)\inv$ on covectors, e.g.\ in $T^*\phi$ \eqref{eqn.TT_phi} below.
}
Equivalently, $\phi$ preserves the pairing iff the \emph{pairing-preservation equation} holds at every $x\in V$:
\begin{equation}\label{eqn.pairing_triangle}
\phi\circ\sharp_x\circ\phi^*=\sharp_{\phi(x)}\colon W^*\to W.
\qedhere
\end{equation}
\end{definition}

\begin{proposition}\label{prop.rvect_monoidal}
Direct sum gives $\rvect$ a symmetric monoidal structure $(0,\oplus)$, with the zero space as unit and direct-sum pairing $\sharp_{V\oplus W}\coloneqq\sharp_V\oplus\sharp_W$ as a smooth section, equivalently the bilinear form at basepoint $(x,y)\in V\oplus W$
\begin{equation}\label{eqn.directsum_pairing}
\pairing{(v,w),(v',w')}_{(x,y)} = \pairing{v,v'}_x+\pairing{w,w'}_y.
\end{equation}
\end{proposition}

\begin{proof}
A pointwise direct sum of smooth sections of linear isomorphisms is again such a section, and \eqref{eqn.directsum_pairing} is direct from $\flat_{(x,y)}=\flat_x\oplus\flat_y$. Coherence is inherited from $(\vect,0,\oplus)$.\qedhere
\end{proof}

\begin{proposition}\label{prop.rvect_smc_action}
The composite $\rvect\to\vect\hookrightarrow\mfd$ is strong symmetric monoidal, so $\rvect$ acts on $\mfd$ via $((V,\sharp_V),M)\mapsto V\times M$.
\end{proposition}

\begin{proof}
The forgetful $\rvect\to\vect$ preserves direct sums (which are products in $\vect$); the inclusion $\vect\hookrightarrow\mfd$ preserves products.\qedhere
\end{proof}

\begin{proposition}\label{prop.canonical_symplectic_pairing}
For any finite-dimensional vector space $V:\vect$, the direct sum $V\oplus V^*$ is a reactive vector space under the \emph{canonical symplectic pairing}: at every basepoint $w\in V\oplus V^*$,
\begin{equation}\label{eqn.canonical_form}
\pairing{(x,\xi),(x',\xi')}_{w} \;=\; \xi'(x)-\xi(x').
\end{equation}
The right-hand side does not depend on $w$, so the section is constant.
\end{proposition}

\begin{proof}
The form in \eqref{eqn.canonical_form} is bilinear. To see that it is nondegenerate, suppose $(x,\xi)$ pairs to $0$ with every $(x',\xi')$. Taking $x'=0$ gives $\xi'(x)=0$ for all $\xi'\in V^*$, hence $x=0$; taking $\xi'=0$ gives $\xi(x')=0$ for all $x'\in V$, hence $\xi=0$.\qedhere
\end{proof}

For the canonical symplectic pairing, under \eqref{eqn.canonical_dual_sum}, the associated sharp map is the constant section
\begin{equation}\label{eqn.canonical_sharp}
\sharp_{V\oplus V^*}\colon V^*\oplus V\to V\oplus V^*,\qquad(\xi,x)\mapsto(x,-\xi).
\end{equation}

\begin{remark}[Sign convention]\label{rmk.swap_pairing}
The bilinear form $\pairing{(x,\xi),(x',\xi')}=\xi'(x)+\xi(x')$
also makes $V\oplus V^*$ a reactive vector space; under \eqref{eqn.canonical_dual_sum}, its sharp map is the swap $(\xi,x)\mapsto(x,\xi)$ whereas \eqref{eqn.canonical_form} has sharp map \eqref{eqn.canonical_sharp}. We use \eqref{eqn.canonical_form} because its antisymmetry is required for the dynamics later in the paper.\qedhere
\end{remark}

\subsection{Cotangent endofunctor and exponential}\label{sec.TT}

For a reactive vector space $(V,\sharp_V):\rvect$, define
\begin{equation}\label{eqn.TT_def}
T^*V\coloneqq V\oplus V^*.
\end{equation}
Under the inclusion functor $\vect\to\mfd$ and the global-chart identifications \eqref{eqn.tangent_vec}, this agrees with the cotangent bundle of $V$ as a manifold.

It is naturally a reactive vector space via the canonical symplectic pairing, whose sharp map is \eqref{eqn.canonical_sharp}.
For a $\rvect$-morphism $\phi\colon V\To{\cong} W$, define
\begin{equation}\label{eqn.TT_phi}
T^*\phi\coloneqq\phi\oplus(\phi^*)\inv.
\end{equation}

\begin{proposition}\label{prop.TT_endofunctors}
Equipping $T^*V$ with the canonical symplectic pairing of \cref{prop.canonical_symplectic_pairing}, the assignments \eqref{eqn.TT_def}, \eqref{eqn.TT_phi} define an endofunctor $T^*\colon\rvect\to\rvect$.
\end{proposition}

\begin{proof}
If $\phi\colon V\to W$ is a linear isomorphism so is $T^*\phi$. Functoriality is obvious. Writing $\psi\coloneqq(\phi^*)\inv\colon V^*\to W^*$, the defining property of $\phi^*$ states that $(\phi^*\xi')(v) = \xi'(\phi v)$ for all $\xi'\in W^*\text{ and }v\in V.$ Setting $\xi'\coloneqq\psi\xi$ and using $\phi^*\circ\psi=\id_{V^*}$, we note that
\begin{equation}\label{eqn.dualeval}
(\psi\xi)(\phi v) = (\phi^*(\psi\xi))(v) = \xi(v).
\end{equation}
To see that $T^*\phi$ preserves pairings, fix any basepoint $w\in T^*V$ and calculate
\begin{align*}
\pairing{T^*\phi(x_1,\xi_1),T^*\phi(x_2,\xi_2)}_{T^*\phi(w)}
&= (\psi\xi_2)(\phi x_1)-(\psi\xi_1)(\phi x_2) && \text{[\eqref{eqn.TT_phi}, \eqref{eqn.canonical_form}]}\\
&= \xi_2(x_1)-\xi_1(x_2) && \text{[\eqref{eqn.dualeval}]}\\
&= \pairing{(x_1,\xi_1),(x_2,\xi_2)}_{w} && \text{[\eqref{eqn.canonical_form}]};
\end{align*}
both sides are independent of $w$ by constancy of the canonical symplectic pairing.
\end{proof}

\begin{remark}[Constancy of $\sharp_{T^*V}$]\label{rmk.constant_canonical_sharp}
The canonical symplectic pairing depends only on the underlying vector space $V$, not on $\sharp_V$, so $\sharp_{V\oplus V^*}$ is the constant section \eqref{eqn.canonical_sharp} even when $\sharp_V$ varies on $V$. Later in \cref{sec.dynamics_functor}, the phase-space dynamics will see only this constant $\sharp_{V\oplus V^*}$, regardless of any variation in $\sharp_V$. However, $\sharp_V$ is not discarded by the framework: it will be used to define the exponential $\exp_V\colon T^*V\to V$ of \eqref{eqn.flow_cot}.
\qedhere
\end{remark}

\begin{proposition}\label{prop.TT_monoidal}
The endofunctor $T^*\colon\rvect\to\rvect$ is strong symmetric monoidal with respect to $(0,\oplus)$.
\end{proposition}

\begin{proof}
The unit comparison is the identity since $T^*0=0\oplus 0^*=0$. The product comparison is the swap
\begin{equation}\label{eqn.Tstar_swap}
T^*(V_1\oplus V_2)\To{\cong}T^*V_1\oplus T^*V_2,\quad ((x_1,x_2),(\xi_1,\xi_2))\mapsto((x_1,\xi_1),(x_2,\xi_2)).
\end{equation}
It is a linear isomorphism, using $(V_1\oplus V_2)^*\cong V_1^*\oplus V_2^*$. To check preservation of pairings, take a second element $((x'_1,x'_2),(\xi'_1,\xi'_2))$ in $T^*(V_1\oplus V_2)$. The canonical symplectic pairing on $T^*(V_1\oplus V_2)$ unfolds via \eqref{eqn.canonical_form} as
\begin{align*}
\pairing{((x_1,x_2),(\xi_1,\xi_2)),\,((x'_1,x'_2),(\xi'_1,\xi'_2))}
&= (\xi'_1,\xi'_2)\bigl((x_1,x_2)\bigr) - (\xi_1,\xi_2)\bigl((x'_1,x'_2)\bigr)\\
&= \xi'_1(x_1)+\xi'_2(x_2)-\xi_1(x'_1)-\xi_2(x'_2).
\end{align*}
The direct-sum pairing on $T^*V_1\oplus T^*V_2$ unfolds via \eqref{eqn.directsum_pairing} and \eqref{eqn.canonical_form} on each factor as
\begin{align*}
\pairing{((x_1,\xi_1),(x_2,\xi_2)),\,((x'_1,\xi'_1),(x'_2,\xi'_2))}
&= \pairing{(x_1,\xi_1),(x'_1,\xi'_1)}+\pairing{(x_2,\xi_2),(x'_2,\xi'_2)}\\
&= \bigl(\xi'_1(x_1)-\xi_1(x'_1)\bigr)+\bigl(\xi'_2(x_2)-\xi_2(x'_2)\bigr).
\end{align*}
The two expansions are equal, so pairings are preserved.\qedhere
\end{proof}

The \emph{exponential} of a reactive vector space $(V,\sharp_V)$ is the bundle map
\begin{equation}\label{eqn.flow_cot}
\exp_V\colon T^*V\to V,\qquad (x,\xi)\longmapsto x+\sharp_x(\xi),
\end{equation}
which at each $(x,\xi)$ is the first-order Euler step from $x$ along the tangent vector $\sharp_x(\xi)\in T_xV\cong V$. In the constant case $\sharp_x=\sharp_0$, $\exp_V(x,\xi)$ coincides with the time-$1$ flow from $x$ of the constant left-invariant vector field $\sharp_0(\xi)$. It is natural in $\rvect$-isomorphisms by linearity and the pointwise pairing-preservation equation \eqref{eqn.pairing_triangle}.

\begin{remark}[Generalization to nilpotent Lie algebras]\label{rmk.rnla_generalization}
Reactive vector spaces are the abelian case of \emph{reactive nilpotent Lie algebras} (RN Lie Algebras): pairs $(\lie g,\sharp)$ of a finite-dimensional nilpotent real Lie algebra and a smooth section $\sharp$ on its underlying vector space in the sense of \cref{def.rvect}. We expect that replacing $\rvect$ by $\rnla$ extends the constructions of this section to the non-abelian setting. A careful treatment is left to future work.

See \cref{rem.cot_as_category} for the next incarnation of this idea, as it traces through the paper.\qedhere
\end{remark}

\section{Potentialized lenses}\label{sec.potentialized_lenses}

Potentialized lenses are ordinary manifold lenses whose backward pass also carries a real-valued potential; after cotangent internalization, its differential drives the induced dynamics. We package them as coKleisli lenses and then parameterize them by reactive vector spaces.

\subsection{Potentialized coKleisli lenses}\label{sec.potentialized_cokleisli}

\begin{lemma}\label{lemma.monoid_to_monad}
If $\cat{C}$ is a symmetric monoidal category and $(M,e,(*))$ is a commutative monoid object in it, then $M\otimes\blank\colon\cat{C}\to\cat{C}$ carries a monoidal monad structure, functorially in $(\cat C,M)$.
\end{lemma}

\begin{proof}
The monad unit and multiplication are $e\otimes\id$ and $(*)\otimes\id$. The monoidal structure has unitor $e\colon I\to M\cong M\otimes I$ and productor
\begin{equation}\label{eqn.monoid_productor}
(M\otimes X)\otimes(M\otimes Y)\cong M\otimes M\otimes X\otimes Y\To{(*)\otimes\id}M\otimes X\otimes Y.
\end{equation}
The coherence diagrams arise from the monoid laws and commutativity of $M$. Functoriality in $(\cat C,M)$ is straightforward.
\end{proof}

Since $(\rr,0,+)$ is a commutative Lie group, \cref{prop.cot_hopf} gives a commutative monoid---in fact Hopf monoid---object $\cot{\rr}$ in $\poly$. By \cref{lemma.monoid_to_monad} there are corresponding monoidal monads $\rr\times\blank$ and $\cot{\rr}\otimes\blank$ on $\mfd$ and $\poly$, and by \cref{prop.backward_comonad} there are corresponding colax monoidal comonads on $\Lens{\mfd}$ and $\Lens{\poly}$. We let $(\Lens{\mfd}^\rr,\rr^0,\times)$ and $(\Lens{\poly}^\rr,\yon,\otimes)$ denote the corresponding coKleisli categories.

A map in $\lmfd^\rr$ is a tuple $f=\big(\binom{\inpt f}{\outp f},U\big)\colon\lensob M\to\lensob N$ with
\[
\outp f\colon\outp M\to\outp N,\qquad
\inpt f\colon\outp M\times\inpt N\to\inpt M,\qquad
U\colon\outp M\times\inpt N\to\rr.
\]
We call such maps \emph{potentialized manifold lenses}.
A map $\lensob p\to\lensob q$ in $\Lens{\poly}^\rr$ is a pair
\[
\outp f\colon\outp p\to\outp q,\qquad
\inpt f\colon\outp p\otimes\inpt q\to\cot{\rr}\otimes\inpt p.
\]

\begin{lemma}\label{lem.cot_lifts_lens_potential}
The strong symmetric monoidal functor $\cot\colon\mfd\to\poly$ lifts to a strong symmetric monoidal functor
\[
\Lens\cot\colon\lmfd^\rr\to\Lens{\poly}^\rr.
\]
\end{lemma}

\begin{proof}
Apply \cref{lem.lens_T_functoriality} with $F=\cot$ (strong symmetric monoidal by \cref{prop.cot_monoidal}) and the monad morphism $\cot{\rr\times\blank}\Rightarrow\cot{\rr}\otimes\cot{\blank}$ supplied by \cref{lemma.monoid_to_monad}.
\end{proof}

\subsection{The potential algebra \texorpdfstring{$\potd$}{d}}\label{sec.potential_algebra}

In \cref{lem.Theta_poly_potential} we will apply the construction of \cref{prop.Theta_T_alpha}, which works for any $\Fun T$-monoid $(z,e,m,\alpha)$ in $\poly$. For simplicity of presentation, and with a view toward our physics application, we take $z\coloneqq\yon$. It has a unique monoid structure, but $\alpha\colon\cot{\rr}\to\yon$ is extra data.

\begin{lemma}\label{lem.alpha_constant}
Let $\Fun{T}\coloneqq(\cot{\rr}\otimes\blank)$. The $\Fun{T}$-monoid structures $(z,e,m,\alpha)$ for which $z=\yon$ are in bijection with real numbers $r:\rr$.
\end{lemma}

\begin{proof}
There is a unique $\otimes$-monoid structure on $\yon$. Maps $\alpha\colon\cot{\rr}\to\yon$ are in bijection with (not-necessarily continuous) covector fields $\omega\colon\rr\to T^*\rr$ on $\rr$, sending $\alpha$ to $\omega(x)\coloneqq\bk{\alpha}{x}(*)$. The first condition of \eqref{eqn.T_monoid} is vacuous. Thus the only condition on $\alpha$ to make it a $\Fun{T}$-monoid is that the following equation holds for all $x_1,x_2\in\rr$
\[
\left(\omega(x_1),\omega(x_2)\right)=
\left(\omega(x_1+x_2),\omega(x_1+x_2)\right)
\]
Setting $x_2\coloneqq 0$, we find $\omega(0)=\omega(x_1)$ for all $x_1$. In other words, $\omega=r$ is constant at some $r:\rr$. And conversely, any constant covector field is a $\Fun{T}$-monoid.
\end{proof}

\begin{remark}[General form]\label{rmk.alpha_general}
\Cref{lem.alpha_constant} generalizes in a couple of ways. First, $\cot{R}$ can be replaced by any commutative Hopf monoid. Second, $\yon$ can be replaced by any $\otimes$-monoid $(z,e,(*))$ in $\poly$ that is \emph{coupled} in the sense that, for every $Z_1,Z_2:z(1)$, the backward action of multiplication $\bk{(*)}{(Z_1,Z_2)}\colon z[Z_1*Z_2]\to z[Z_1]\times z[Z_2]$ is surjective. For any commutative Hopf monoid $m$ in $\poly$ and any coupled $\otimes$-monoid $z$, the $(m\otimes\blank)$-monoid structures on $z$ for which the $m(1)$-action on $z(1)$ is trivial are in bijection with $m[e_m]$, the directions of $m$ at its unit position.

As examples, note that any $\otimes$-monoid of the form $M\yon=\sum_{m\in M}\yon$ for a monoid $(M,\cdot,1)$ in $\smset$ is coupled trivially (every position has one direction), recovering the $\yon$ case. A more interesting example is the polynomial $\mathrm{rand}\coloneqq\sum_{N:\nn}\sum_{P\in\Delta_N}\yon^N$ of finite random variables~\cite{Spivak2023lotteries}, which underlies (the monad of) the operad of simplices~\cite{leinster2021entropy}. For $m\coloneqq\cot G$ with $G$ a commutative Lie group, $m[e_m]=T^*_{e_G}G=\lie g^*$, the dual of the Lie algebra; for $G\coloneqq\rr$ this recovers \cref{lem.alpha_constant}.
\end{remark}

The role of $\rr$ in this section is to act as the recipient of \emph{potentials}: specializing \cref{lem.alpha_constant} to $m\coloneqq\cot\rr$ and $z\coloneqq\yon$, we choose the homomorphism corresponding to $r\coloneqq+1$ and write the corresponding algebra map as
\begin{equation}\label{eqn.d_potential}
\potd\colon\cot{\rr}\to\yon,\qquad\bk{\potd}{x}(*)\coloneqq +1\in T^*_x\rr.
\end{equation}
We call it $\potd$ because this is the choice for which potentials contribute their usual differentials. Indeed, for a smooth map $U\colon X\to\rr$, the composite $\potd\circ\cot{U}\colon\cot{X}\to\yon$ corresponds to the covector field $dU$ on $X$: tracing on directions,
\[
\bk{\potd\circ\cot{U}}{x}(*)=(T_x U)^\top(+1)=dU|_x
\]
exactly as in \eqref{eqn.differential}.

%--------------------------------------------------------------------
\section{Smooth rewiring diagrams}\label{sec.W_choice}
%--------------------------------------------------------------------

We can now settle the choice of composition syntax $\cat{W}$ deferred at the end of \cref{sec.wd_operads}: we take it to be the underlying operad of $\potlens$. We call its multimorphisms \emph{smooth rewiring diagrams}. Thus a smooth rewiring diagram $f\colon\lensob{X_1}\otimes\cdots\otimes\lensob{X_K}\to\lensob{Y}$ has the form $f=\left((V,\sharp_V),\binom{\inpt f}{\outp f},U\right)$, namely a reactive vector space $(V,\sharp_V):\rvect$ called the \emph{parameter space}, smooth maps
\begin{equation}\label{eqn.plens_map}
\outp f\colon V\times\prod_{i=1}^K\outp X_i\to\outp Y,\qquad
\inpt f\colon V\times\prod_{i=1}^K\outp X_i\times\inpt Y\to\prod_{i=1}^K\inpt X_i,
\end{equation}
called the \emph{output map} and the \emph{input maps}, and a smooth function
\begin{equation}\label{eqn.plens_potential}
U\colon V\times\prod_{i=1}^K\outp X_i\times\inpt Y\to\rr,
\end{equation}
called the \emph{potential}.

There is a chain of functors
\[
\Lens{\finset\op}\To{\Lens{\rr^-}}\lmfd\To{\Lens{\eta}}\lmfd^\rr\To{\Para_{\rr^0}}\potlens
\]
where $\eta\colon\id_\mfd\Rightarrow\rr\times\blank$ is the unique map from the initial monad $\id$, and $\Para_{\rr^0}$ regards a potentialized lens as a parameterized one with unit parameter $\rr^0$. This chain gives rise to progressively richer smooth rewiring diagrams.

The simplest---those coming from the leftmost category in the chain---are static wiring diagrams, which come from ``prisms,'' i.e.\ lenses in $\finset\op$, as we saw in \cref{ex.lens_finsetop}. In this case the maps in \eqref{eqn.plens_map} have trivial $V=\rr^0$-factor, all the maps factor as projections and diagonals, and the potential is zero. These simplest maps give the syntax for something like traced symmetric monoidal semicategories, as discussed in \cref{sec.plenspot_ops}.

\begin{remark}
The wiring diagrams used merely to arrange boxes in the examples below are static in this sense: the parameter space is the one-point space $\rr^0$, so the routing maps are fixed smooth maps. Dynamic rewiring can be represented by allowing the routing maps and potentials to depend on a reactive parameter. We do not pursue such examples here.
\end{remark}

We can realize each such static wiring diagram as a lens between manifolds via $\Lens{\rr^-}$ (\cref{lemma.lens_rr}), but compositions coming from $\lmfd$ are more general: there are many more maps $M\times N\to M$ than just the projection. Moving to $\lmfd^\rr$ adds a potential but still no parameter space $V$: it assigns a real number to the interaction data consisting of the internal-box outputs together with the external-box input, e.g.\ a prediction error.

Finally, the general smooth rewiring diagrams are maps in $\potlens$: the interaction pattern itself depends smoothly on a parameter in a reactive vector space $(V,\sharp_V)$, and under the dynamics functor that parameter is updated by the differential of the potential. Exactly how these smooth rewiring dynamics work is the subject of \cref{ch.potential_driven_dynamics}.

We first explain how cotangent parameterizations are presented to $\org$ as ordinary coalgebra state.

\subsection{Coalgebras as Para over the store action}\label{sec.org_as_para}

The Para construction over the store action of $\smsetiso$ on $\poly$ (\cref{def.store_action}) repackages the truncation $\org_{\cong}$ (with only coalgebra isomorphisms as 2-cells) exactly:

\begin{proposition}\label{prop.org_as_para}
There is an isomorphism of $(2,1)$-categories
\[
\para{\Cat{Set}_{\cong}}{\poly}\To{\cong}\org_\cong
\]
\end{proposition}

\begin{proof}
For each category---$\para{\Cat{Set}_{\cong}}{\poly}$ and $\org_\cong$---the object set is $\ob\poly$ and the mapping groupoids $p\to q$ agree
\begin{align*}
	\para{\Cat{Set}_{\cong}}{\poly}(p,q)&=
  \sum_{S:\smsetiso}\poly(S\yon^S\otimes p, q)\\&\cong
  \sum_{S:\smsetiso}\poly(S\yon^S,[p,q])\\&\cong
  \sum_{S:\smsetiso}\poly(S,[p,q]\tri S)=\org_\cong(p,q)
\end{align*}
by \cref{eqn.dirichlet_hom,prop.coalg_as_poly_map}. It remains to show that the identities and composites agree.

In both cases the identity is indexed by the monoidal unit $1$, and $1\To{\id}\poly(p,p)=[p,p](1)$ and $\yon\To{\id}[p,p]$ are identified as above. Given composable maps $p\To{(S,\varphi)}q\To{(T,\psi)}r$, in both cases the composite is of the form $(TS,\psi\circ\varphi)$, and the same identifications match these composites.
\end{proof}

\begin{lemma}\label{lem.poly_to_org}
Let $F\colon\rvect\to\smsetiso$ be strong symmetric monoidal, and let $\rvect$ act on $\poly$ via the strong monoidal composite $\Store\circ F\colon\rvect\to\poly$ as in \cref{prop.para_strong_induced}. There is an identity-on-objects normal lax symmetric monoidal functor
\[
D_F\colon\para{\Store\circ F}{\poly}\to\org_\cong.
\]
\end{lemma}

\begin{proof}
The induced action sends $(V,p)\mapsto \Store(F(V))\otimes p=F(V)\yon^{F(V)}\otimes p$. The functor $F$ fills the (commuting) action square
\[
\begin{tikzcd}[ampersand replacement=\&, column sep=60pt]
\rvect\times\poly\ar[r,"\Store(F(\blank))\otimes\blank"]\ar[d,"F\times\poly"', ""{name=L}]\& \poly\ar[d, equal, ""' {name=R}]\\
\smsetiso\times\poly\ar[r,"\Store(\blank)\otimes\blank"']\& \poly.
\end{tikzcd}
\]
\Cref{prop.para_strong_induced,prop.para_square} gives $\para{\Store\circ F}{\poly}\to\para{\smsetiso}{\poly}$, and composing with $\para{\smsetiso}{\poly}\cong\org_\cong$ from \cref{prop.org_as_para} yields the claim. For normality, note that $F(0)\cong 1$ so $D_F$ sends the unit $(0,\yon)$ to $\Store(F(0))\otimes\yon\cong\yon$.
\end{proof}

\subsection{Cotangent storages}\label{sec.cotangent_storages}

The Para description of $\org_\cong$ lets us compare cotangent parameterizations with ordinary store parameterizations, i.e.\ coalgebras (see \cref{prop.org_as_para}). Recall the inclusion $\rvect\to\vect\hookrightarrow\mfd$ from \cref{prop.rvect_smc_action} and $\Store(S)\coloneqq S\yon^S$ from \cref{def.store_action}.

\begin{definition}[Cotangent storage]\label{def.cotangent_storage}
A \emph{cotangent storage} is a pair $\mathfrak{s}=(F,\vartheta)$, where $F\colon\rvect\to\smsetiso$ is strong symmetric monoidal and $\vartheta$ is a monoidal natural transformation filling the square
\begin{equation}\label{eqn.cotangent_storage_square}
\begin{tikzcd}[ampersand replacement=\&]
\rvect\ar[r,"\inc"]\ar[d,"F"', ""{name=left}]
\& \mfd\ar[d,"\cot", ""' {name=right}]\\
\smsetiso\ar[r,"\Store"'] \& \poly
\arrow[Rightarrow, from=left, to=right, shorten <=7mm, shorten >=7mm, "\vartheta"]
\end{tikzcd}
\end{equation}
A \emph{morphism} $\alpha\colon(F,\vartheta)\to(F',\vartheta')$ of cotangent storages is a monoidal natural transformation $\alpha\colon F\Rightarrow F'$ such that $\vartheta'\circ\Store(\alpha)=\vartheta$. We denote this category by $\cotstor$.
\end{definition}

Let $\para{\cot}{\poly}$ denote the Para construction for the action $V\cdot p\coloneqq\cot{V}\otimes p$ induced by $\cot\circ\inc$.

\begin{proposition}\label{prop.store_refinement}
There is a functor $\Psi_{\blank}\colon\cotstor\to\bbcat(\para{\cot}{\poly},\org_\cong)$. That is, every cotangent storage $\mathfrak{s}$ induces a normal lax symmetric monoidal functor
\[
\Psi_{\mathfrak{s}}\colon\para{\cot}{\poly}\to\org_\cong
\]
and every morphism $\alpha\colon\mathfrak{s}\to\mathfrak{s}'$ induces a monoidal pseudonatural transformation
\[
\Psi_\alpha\colon\Psi_{\mathfrak{s}}\Rightarrow\Psi_{\mathfrak{s}'}.
\]
\end{proposition}

\begin{proof}
Write $\mathfrak{s}=(F,\vartheta)$ and let
\[
D_F\colon\para{\Store\circ F}{\poly}\to\org_\cong
\]
be the functor of \cref{lem.poly_to_org}. By \cref{prop.para_strong_induced,prop.para_square}, the action square $\vartheta\colon\Store\circ F\Rightarrow\cot\circ\inc$ induces a strong symmetric monoidal functor
\[
\Para_{\mathfrak{s}}\colon\para{\cot}{\poly}\to\para{\Store\circ F}{\poly}.
\]
Define $\Psi_{\mathfrak{s}}\coloneqq D_F\circ\Para_{\mathfrak{s}}$, which is normal lax monoidal because $\Para_{\mathfrak s}$ is strong and $D_F$ is normal lax monoidal by \cref{lem.poly_to_org}.

For $\alpha\colon\mathfrak{s}\to\mathfrak{s}'=(F',\vartheta')$, the monoidal natural transformation $\Store(\alpha)\colon\Store\circ F\Rightarrow\Store\circ F'$ gives
\[
\alpha^*\colon\para{\Store\circ F'}{\poly}\to\para{\Store\circ F}{\poly},
\]
and the composite $\alpha^*\circ\Para_{\mathfrak{s}'}$ is the Para functor induced by the composite action square $\vartheta'\circ\Store(\alpha)\colon\Store\circ F\Rightarrow\cot\circ\inc$. The storage-morphism condition $\vartheta'\circ\Store(\alpha)=\vartheta$ is an equality of natural transformations, so by the strict functoriality of \cref{prop.para_square} we obtain $\alpha^*\circ\Para_{\mathfrak{s}'}=\Para_{\mathfrak{s}}$ as functors. The components $\alpha_V\colon F(V)\to F'(V)$ give a monoidal pseudonatural transformation $D_F\circ\alpha^*\Rightarrow D_{F'}$; precomposing with $\Para_{\mathfrak{s}'}$ gives $\Psi_\alpha$.
\end{proof}

We now get to our bifurcation between learning and physics: which state set the cotangent parameterization presents to $\org$. In learning, we will be storing the points of $V$, whereas in physics we will be storing the phase points of $T^*V$. These are formalized in \cref{prop.rvect_polynomial} and \cref{lem.phase_storage}.

\begin{proposition}\label{prop.rvect_polynomial}
There is a cotangent storage, which we call \emph{configuration storage}, given by
\[\store{\conf}\coloneqq(\absval{\blank},\theta)\]
where $\absval{\blank}\colon\rvect\to\smsetiso$ sends a reactive vector space to its underlying set of points $V\mapsto \absval{V}$ and where $\theta_V\colon V\yon^V\To{\cong}\cot{V}$ is the polynomial map, natural in $V:\rvect$, which is identity on positions and, given on directions at $x\in V$ by the exponential \eqref{eqn.flow_cot}
\begin{equation}\label{eqn.directions_sharp}
T^*_xV\To{\eqref{eqn.tangent_vec}}V^*\To{\sharp_x}V\To{x+\blank}V,
\qquad
\xi\longmapsto x+\sharp_x(\xi).
\end{equation}
\end{proposition}

\begin{proof}
On positions, both composite functors $\Store\circ\absval{\blank}$ and $\cot\circ\inc$ send $V$ to its underlying set, so we can take the on-positions component of $\theta_V$ to be the identity. At each $x\in V$, \eqref{eqn.directions_sharp} is the composite of two linear isomorphisms with translation by $x$, hence a bijection. So $\Store(\absval{V})=V\yon^V\cong\cot{V}$ in $\poly$ for each $V$. 

For naturality at a $\rvect$-isomorphism $\phi\colon V\to W$, the on-positions square commutes by definition. On directions at $x:V$, we must check that the two backward composites $T^*_{\phi(x)}W\to V$ agree:
\begin{align*}
\xi\;&\Mapsto{\phi^*}\;\phi^*\xi\;\Mapsto{\sharp_x}\;\sharp_x(\phi^*\xi)\;\Mapsto{x+\blank}\;x+\sharp_x(\phi^*\xi), && \text{[$\theta_V\circ\cot{\phi}$]}\\
\xi\;&\Mapsto{\sharp_{\phi(x)}}\;\sharp_{\phi(x)}(\xi)\;\Mapsto{\phi(x)+\blank}\;\phi(x)+\sharp_{\phi(x)}(\xi)\;\Mapsto{\phi^{-1}}\;x+\phi^{-1}(\sharp_{\phi(x)}\xi) && \text{[$\Store(\phi)\circ\theta_W$]}.
\end{align*}
The two are equal iff $\sharp_x\circ\phi^*=\phi^{-1}\circ\sharp_{\phi(x)}$, which is the pointwise pairing-preservation equation \eqref{eqn.pairing_triangle} at $x$. Monoidality follows from the direct-sum convention $\sharp_{V_1\oplus V_2}=\sharp_{V_1}\oplus\sharp_{V_2}$ (\cref{prop.rvect_monoidal}).\qedhere
\end{proof}

\begin{remark}\label{rmk.rvect_fiberwise_addition}
By \cref{prop.comonads_cats}, a $\tri$-comonoid structure on $V\yon^V$ is a category whose object set is $V$ and whose arrows out of each object are indexed by $V$. By \cref{ex.store}, the canonical such structure is the codiscrete category on $V$: there is exactly one morphism $x\to x'$ for each pair, and the direction-set $V$ at position $x$ is interpreted as the set of codomains.

Transporting this $\tri$-comonoid structure to $\cot{V}$ along the iso of \cref{prop.rvect_polynomial}, a covector $\xi\in T^*_xV$ corresponds to the unique morphism $x\To{\xi} x+\sharp_x(\xi)=:\cod(\xi)$ in the codiscrete category on $V$. The identity at $x$ corresponds to the zero covector $0\in T^*_xV$, since $x+\sharp_x(0)=x$. Composition of $\xi\in T^*_xV$ with $\xi'\in T^*_{x+\sharp_x(\xi)}V$ corresponds to the unique covector $\xi\star\xi'\in T^*_xV$ for which
\begin{equation}\label{eqn.twisted_composition}
\sharp_x(\xi\star\xi')=\sharp_x(\xi)+\sharp_{x+\sharp_x(\xi)}(\xi'),
\qquad\text{i.e.}\qquad
\xi\star\xi'=\xi+\flat_x\bigl(\sharp_{\cod(\xi)}(\xi')\bigr),
\end{equation}
since both produce the codiscrete morphism with codomain $x+\sharp_x(\xi)+\sharp_{x+\sharp_x(\xi)}(\xi')$. Thus $\sharp_V$ identifies $\cot{V}$ with the codiscrete category on $V$, with codomain map $(x,\xi)\mapsto x+\sharp_x(\xi)$ and the $\sharp_V$-twisted composition \eqref{eqn.twisted_composition}. In the constant case $\sharp_x=\sharp_0$, \eqref{eqn.twisted_composition} collapses to fiberwise addition $\xi\star\xi'=\xi+\flat(\sharp(\xi'))=\xi+\xi'$.\qedhere
\end{remark}

\begin{remark}[Gradient-based learning]\label{rmk.cotangent_learners}
The dynamics for configuration storage recover the gradient-based learning behavior underlying the deep learning dynamic prop of~\cite{shapiro2022dynamic}. Indeed, this behavior arises via a functor $\Phi_{\conf}\colon\potlens\to\org$, which we will define in \cref{thm.functor} (and unpack in \cref{sec.configuration_dynamics}); the learning rate is absorbed into the sharp $\sharp_V$ of the parameter space (e.g.\ on Euclidean parameter spaces, $\sharp_x=-\eta_{\mathrm{LR}}\sharp_{\mathrm{Euc}}$, where $\sharp_{\mathrm{Euc}}\colon V^*\To{\cong}V$ is the Euclidean sharp).
\end{remark}

We now turn to physics, where the stored state is a phase point $(x,\xi)\in T^*V=V\oplus V^*$, as in \eqref{eqn.TT_def}, with \emph{position} $x$ and \emph{momentum} $\xi$ rather than a point $x\in V$. Its cotangent space decomposes as
\[
T^*_{(x,\xi)}(T^*V)\cong T^*_xV\oplus T^*_\xi(V^*)\cong V^*\oplus V,
\]
using \eqref{eqn.T_products}, \eqref{eqn.tangent_vec}, and \eqref{eqn.TT_def}.

\begin{definition}[Legendre projection]\label{def.legendre_projection}
Let $(V,\sharp)$ be a reactive vector space. The \emph{Legendre projection} $\rho_V\colon\cot{T^*V}\to\cot{V}$ is given on positions by $(x,\xi)\mapsto x$, and for each $(x,\xi)$ given on directions by
\[
T^*_xV\cong V^*\To{\xi_V\mapsto(\xi_V,\,\sharp_x(\xi))}V^*\oplus V\cong T^*_{(x,\xi)}(T^*V).
\]
\end{definition}

Thus, at a phase point $(x,\xi)$, the Legendre projection sends a covector $\xi_V\in T^*_xV$ to the covector $(\xi_V,\sharp_x(\xi))\in T^*_{(x,\xi)}(T^*V)$.


This gives us a second storage in the sense of \cref{def.cotangent_storage}.

\begin{lemma}\label{lem.phase_storage}
There is a cotangent storage, which we call \emph{phase-space storage}, given by
\[
\store{\phase}\coloneqq\bigl(\absval{T^*\blank},\,\rho\circ\theta_{T^*\blank}\bigr).
\]
The first component sends $V\mapsto\absval{T^*V}$, the underlying set of its cotangent bundle, and the second component at $V:\rvect$ composes the configuration-storage component $\theta$ at $T^*V$ (see \cref{prop.rvect_polynomial}) with the Legendre projection,
\[
\Store(\absval{T^*V})\To{\theta_{T^*V}}\cot{T^*V}\To{\rho_V}\cot{V}.
\]
\end{lemma}

\begin{proof}
The functor $T^*\colon\rvect\to\rvect$ is strong symmetric monoidal by \cref{prop.TT_monoidal}, so the composite $\absval{T^*\blank}\colon\rvect\to\smsetiso$ is strong symmetric monoidal. The components $\rho_V$ assemble into a monoidal natural transformation
\[
\begin{tikzcd}[ampersand replacement=\&, column sep=50pt]
\rvect\ar[r,bend left=25,"\cot{T^*\blank}", ""{name=U,below}]\ar[r,bend right=25,"\cot{\blank}"', ""{name=D,above}]\& \poly.
\arrow[Rightarrow, from=U, to=D-|U, pos=.4, "\rho"]
\end{tikzcd}
\]
Indeed, monoidality follows from the direct-sum convention $\sharp_{V_1\oplus V_2}=\sharp_{V_1}\oplus\sharp_{V_2}$ (\cref{prop.rvect_monoidal}), and naturality in $\rvect$-isomorphisms follows from the pointwise pairing-preservation equation \eqref{eqn.pairing_triangle} at each $(x,\xi)\in T^*V$.
Therefore $\rho\circ\theta_{T^*\blank}$ is a monoidal natural transformation $\Store\circ\absval{T^*\blank}\Rightarrow\cot\circ\inc$, i.e.\ a cotangent storage.
\end{proof}

In other words, $\rho\circ\theta_{T^*\blank}\colon T^*V\yon^{T^*V}\to \cot{V}$ is given succinctly by
\begin{equation}\label{eqn.phase_storage_update}
(x,\xi)\mapsto\bigl(x,\xi'\mapsto (x+\sharp_x(\xi),\,\xi-\xi')\bigr)
\end{equation}

\section{The dynamics functor}\label{sec.dynamics_functor}
%--------------------------------------------------------------------

The smooth rewiring diagrams of \cref{sec.W_choice} become smooth rewiring dynamics by first internalizing them as parameterized polynomial maps and then applying a cotangent storage.

\begin{lemma}\label{lem.potlens_to_para_poly}
There is a normal lax symmetric monoidal functor
\[
\Phi'\colon\potlens\to\para{\cot}{\poly}.
\]
\end{lemma}

\begin{proof}
By \cref{def.potlens}, $\potlens=\para{\rvect}{\lmfd^\rr}$. We have a strong monoidal functor $\Lens\cot\colon\lmfd^\rr\to\Lens{\poly}^\rr$ from \cref{lem.cot_lifts_lens_potential} and a normal lax monoidal $\Theta_{\potd}\colon\Lens{\poly}^\rr\to\poly$ from
\cref{lem.Theta_poly_potential}. The action square for $\Lens\cot$ and the action square for $\Theta_{\potd}$ recorded in \cref{cor.parameterized_representation} induce, by \cref{prop.para_square}, the two normal lax monoidal maps below; the desired functor is their composite:
\[
\potlens\To{\para{\rvect}{\Lens\cot}}
\para{\rvect}{\Lens{\poly}^\rr}\To{\para{\rvect}{\Theta_{\potd}}}
\para{\cot}{\poly}.
\]
\end{proof}
The functor $\Phi'$ acts on objects by
\[\Phi'\lensob{M}\coloneqq\cot{\outp{M}}\otimes\ihom{\cot{\inpt{M}},\yon}.\] 
And $\Phi'$ sends a smooth rewiring diagram as in \eqref{eqn.plens_map} and \eqref{eqn.plens_potential} to a $\cot{V}$-parameterized polynomial map of the form
\[
\cot{V}\otimes
\Phi'\lensob{X_1}\otimes\cdots\otimes\Phi'\lensob{X_K}
\to
\Phi'\lensob{Y}.
\]
This is the bulk of the construction. Our main functor of interest $\Phi_{\mathfrak{s}}$, which depends on a cotangent storage $\mathfrak{s}$ (see \cref{def.cotangent_storage}), acts the same on objects:
\[\Phi_{\mathfrak{s}}\lensob{M}=\Phi'\lensob{M}.\]
What \cref{thm.functor} does is to first rearrange to
\[
\cot{V}\to
\left[
  \Phi_\mathfrak{s}\lensob{X_1}\otimes\cdots\otimes\Phi_\mathfrak{s}\lensob{X_K},
  \Phi_\mathfrak{s}\lensob{Y}
\right],
\]
then use $\mathfrak{s}$ to turn the $\cot{V}$ into something of the form $S\yon^S$ for some set $S$, and finally, to unfold that to a coalgebra
\[
S\to\left[
  \Phi_\mathfrak{s}\lensob{X_1}\otimes\cdots\otimes\Phi_\mathfrak{s}\lensob{X_K},
  \Phi_\mathfrak{s}\lensob{Y}
\right](S)
\]
The precise relationship between $S$ and $V$ will depend on the cotangent storage: in our two main cases of interest it is the configuration space $\absval{V}$ and the phase space $\absval{T^*V}$; see \eqref{eqn.our_phis}.

\begin{theorem}\label{thm.functor}
For every cotangent storage $\mathfrak{s}=(F,\vartheta)$, there is a normal lax symmetric monoidal functor
\[
\Phi_{\mathfrak{s}}\colon\potlens\to\org.
\]
A morphism $\alpha\colon\mathfrak{s}\to\mathfrak{s}'$ of cotangent storages induces a monoidal pseudonatural transformation $\Phi_\alpha\colon\Phi_{\mathfrak{s}}\Rightarrow\Phi_{\mathfrak{s}'}$.
\end{theorem}

\begin{proof}
Define $\Phi_{\mathfrak{s}}$ to be the composite of the normal lax monoidal functors below, given by \cref{lem.potlens_to_para_poly,prop.store_refinement}:
\[
\potlens\To{\Phi'}
\para{\cot}{\poly}\To{\Psi_{\mathfrak{s}}}
\org_\cong\hookrightarrow\org.
\]

For the second statement, \cref{prop.store_refinement} gives a monoidal pseudonatural transformation $\Psi_\alpha\colon\Psi_{\mathfrak{s}}\Rightarrow\Psi_{\mathfrak{s}'}$; whiskering with $\Phi'$ yields the desired $\Phi_\alpha\coloneqq\Psi_\alpha*\Phi'\colon\Phi_{\mathfrak{s}}\Rightarrow\Phi_{\mathfrak{s}'}$.\qedhere
\end{proof}

Let $\store{\conf}$ and $\store{\phase}$ be the configuration and phase-space storages of \cref{prop.rvect_polynomial,lem.phase_storage}. Our main two functors of interest are:
\begin{equation}\label{eqn.our_phis}
\Phi_{\conf}\coloneqq\Phi_{\store{\conf}}
\qqand
\Phi_{\phase}\coloneqq\Phi_{\store{\phase}}.
\end{equation}

%--------------------------------------------------------------------
\section{Phase-space dynamics \texorpdfstring{$\Phi_{\phase}$}{Phi phase}}\label{sec.phase_dynamics}
%--------------------------------------------------------------------

For phase-space storage, the functor $\Psi_{\store{\phase}}$ presents a $\cot{V}$-parameter by the store polynomial on $S\coloneqq\absval{T^*V}$:
\[
S\yon^S\To{\theta_{T^*V}}\cot{T^*V}\To{\rho_V}\cot{V}.
\]
A state consists of a position and a momentum $(x,\xi)\in T^*V$, and an incoming covector $\xi'\in T^*_xV$ updates that state to $(x+\sharp_x(\xi),\,\xi-\xi')$
 by \eqref{eqn.phase_storage_update}. But the majority of what takes place under $\Phi_\mathfrak{s}$ is still compressed within the $\Phi'$ factor from \cref{lem.potlens_to_para_poly}. So we now unpack $\Phi_{\phase}$ in total, tracing each term and sign in the resulting formulas back to the definitions that produced it.

Let $\inpt M,\outp M:\mfd$ be manifolds, and write
\[\Omega(M)\coloneqq\{\omega\colon M\to T^*M\mid\pi\circ\omega=\id\}\]
for the set of (not-necessarily continuous) \emph{covector fields} on $M$. The category $\poly$ remembers only the underlying sets of positions and directions, not their topology, so we take all set-theoretic sections. A smooth map $f\colon M\to N$ induces a \emph{pullback} $f^*\colon\Omega(N)\to\Omega(M)$ defined by $(f^*\omega)(m)\coloneqq(T_m f)^\top\omega(f(m))$.

\paragraph{The action of $\Phi_{\phase}$ on objects.}
The functor $\Phi_{\phase}$ acts on objects as follows:
\begin{equation}\label{eqn.Phi_on_obs}
\Phi_{\phase}\lensob M=
\cot{\outp M}\otimes\ihom{\cot{\inpt M},\yon}\cong
\sum_{(\outp m,\omega):\outp M\times\Omega(\inpt M)}\yon^{\left(T^*_{\outp{m}}\outp M\right)\times\inpt M}.
\end{equation}
A position in $\Phi_{\phase}\lensob M$ is a pair $(\outp m,\omega)$ where $\outp m\in\outp{M}$ is a point and $\omega\in\Omega(\inpt M)$ is a covector field. A direction at $(\outp m,\omega)$ is a pair $(\xi,\inpt m)$ where $\xi:T^*_{\outp{m}}\outp M$ is a covector and $\inpt m\in\inpt M$ is a point.

\paragraph{The action of $\Phi_{\phase}$ on morphisms.}
Describing the action of $\Phi_{\phase}$ on morphisms will extend to the end of this section, \cref{sec.phase_dynamics}. Let $(V,\sharp_V):\rvect$ and let
$f\colon V\cdot\lensob M\to\lensob N$
be a morphism in $\potlens$, i.e.\ a tuple $\left(\binom{\inpt f}{\outp f},U\right)$ as in \eqref{eqn.para_potential_lens_maps}:
\begin{equation}\label{eqn.para_potential_lens_maps}
\outp f\colon V\times\outp M\to\outp N,\qquad
\inpt f\colon V\times\outp M\times\inpt N\to\inpt M,\qquad
U\colon V\times\outp M\times\inpt N\to\rr.
\end{equation}
It is sent by $\Phi_{\phase}$ to a $[\Phi_{\phase}\lensob M,\Phi_{\phase}\lensob N]$-coalgebra whose carrier is the underlying set of $T^*V$,
\begin{equation}\label{eqn.state_space}
S\coloneqq\absval{T^*V}\cong V\oplus V^*;
\end{equation}
we write $s=(x,\xi)\in S$ for position $x\in V$ and momentum $\xi\in V^*$. Although the coalgebra remembers only the set $S$, the state update below uses the canonical symplectic pairing on $T^*V$. Its sharp map is
\begin{equation}\label{eqn.sharp_S}
\sharp_S\colon S^*\to S,\qquad (\xi',x')\mapsto(x',-\xi'),
\end{equation}
specializing \eqref{eqn.canonical_sharp}.

We now unpack the coalgebra function itself,
\[
S\To{\Phi_{\phase}(V,\sharp_V,f)}
\left[\Phi_{\phase}\lensob M,\Phi_{\phase}\lensob N\right]\tri S.
\]
Given a state $s\coloneqq(x,\xi)\in S$ and a position $a\coloneqq(\outp m,\omega_M):\outp M\times\Omega(\inpt M)$, define the output point using $\outp{f}$ from \eqref{eqn.para_potential_lens_maps}:
\begin{equation}\label{eqn.outpn}
\outp n\coloneqq\outp f(x,\outp m)
\end{equation}
and the output covector field $\omega_N\colon\inpt N\to T^*\inpt N$ using the rest of \eqref{eqn.para_potential_lens_maps}:
\begin{equation}\label{eqn.omegaprime}
\omega_N(\inpt n)\coloneqq(\inpt f(x,\outp m,\blank))^*\omega_M\big|_{\inpt n}\;+\;d(U(x,\outp m,\blank))\big|_{\inpt n}.
\end{equation}
The first term is the pullback of $\omega_M$ along the partial map $\inpt f(x,\outp m,\blank)\colon\inpt N\to\inpt M$; the second is the differential of the potential $U(x,\outp m,\blank)\colon\inpt N\to\rr$ at $\inpt n$, in the sense of \eqref{eqn.differential}.%
\footnote{The $+1$ that turns the second summand into $dU$ comes from \eqref{eqn.d_potential}; the $+$ between summands is the cotangent splitting $T^*(\rr\times\inpt M)\cong T^*\rr\oplus T^*\inpt M$ (\cref{sec.manifolds_notation}).} Thus the readout position is the pair,
\[
b\coloneqq\bigl(\outp n,\,\omega_N\bigr)\;\in\;\outp N\times\Omega(\inpt N).
\]


Now given a direction $(\xi_N,\inpt n):T^*_{\outp n}\outp N\times\inpt N=\Phi_{\phase}\lensob N[b]$, the coalgebra function $\Phi_{\phase}(V,\sharp_V,f)$ at $(s,a)$ produces a direction in $T^*_{\outp m}\outp M\times\inpt M$ as follows. Let
\begin{equation}\label{eqn.inptm}
\inpt m\coloneqq\inpt f(x,\outp m,\inpt n)
\end{equation}
and define
\begin{equation}\label{eqn.bigtheta}
(\xi_V,\,\xi_M,\,\xi_{\inpt N})\coloneqq (T_{(x,\outp m)}\outp f)^\top\xi_N \;+\; (T_{(x,\outp m,\inpt n)}\inpt f)^\top\omega_M(\inpt m) \;+\; dU\big|_{(x,\outp m,\inpt n)}\;
\end{equation}
where $(\xi_V,\,\xi_M,\,\xi_{\inpt N}):V^*\oplus T^*_{\outp m}\outp M\oplus T^*_{\inpt n}\inpt N$.%
\footnote{Each summand is a cotangent pullback: $\xi_N$ along $\outp f$, $\omega_M(\inpt m)$ along $\inpt f$, and $+1$ along $U$ (via $\potd$, \eqref{eqn.d_potential}); the $+$'s are the cotangent splitting of $V\times\outp M\times\inpt N$ (\cref{sec.manifolds_notation}), morally the domain of the maps in \eqref{eqn.para_potential_lens_maps}. Throughout, we silently use the canonical chart identification \eqref{eqn.tangent_vec} to treat covectors at points of vector spaces as elements of the dual.}
Note that the first summand naturally lands in $V^*\oplus T^*_{\outp m}\outp M$ and has been extended by $0$ in the remaining $\inpt N$-factor, so by \eqref{eqn.omegaprime} we have $\omega_N(\inpt n)=\xi_{\inpt N}$.

All of the work has now been done: the coalgebra at $(s,a)$ on $(\xi_N,\inpt n)$ returns the direction
\[
(\xi_M,\,\inpt m):T^*_{\outp m}\outp M\times\inpt M=\Phi_{\phase}\lensob M[a]
\]
and updates the state (from its original $s=(x,\xi)$) to
\begin{equation}\label{eqn.state_update}
s+\sharp_S(\xi_V,\sharp_x(\xi))=\bigl(x+\sharp_x(\xi),\,\xi-\xi_V\bigr).
\end{equation}
Equation \eqref{eqn.state_update} is \eqref{eqn.phase_storage_update} with $\xi'=\xi_V$; its left-hand side records where the three pieces of this update come from. The sum $s+\sharp_S(\blank)$ is the exponential of the reactive vector space $T^*V$ on the underlying set $S$, \eqref{eqn.flow_cot}; the use of $\sharp_S$ comes from the canonical symplectic pairing on $T^*V$, \eqref{eqn.canonical_sharp}, which is constant in $s$ regardless of variation in $\sharp_V$ (\cref{rmk.constant_canonical_sharp}); and the pair $(\xi_V,\sharp_x(\xi))\in T^*_sS$ comes from the Legendre projection at $(x,\xi)$, \cref{def.legendre_projection}. The right-hand side is the computation: \eqref{eqn.canonical_sharp} gives $\sharp_S(\xi_V,\sharp_x(\xi))=(\sharp_x(\xi),-\xi_V)$, then componentwise addition with $s=(x,\xi)$ produces $(x+\sharp_x(\xi),\,\xi-\xi_V)$.%
\footnote{
\Cref{eqn.state_update} can be read two ways. As the defining equation of a discrete dynamical system, it is exact: that's the perspective of \cref{sec.wave_equation}, where the recurrence \emph{is} the discrete wave equation we want. But as a numerical time-stepper for the continuous Hamiltonian flow on $T^*V$, it is one step of explicit Euler integration---and the explicit-Euler discretisation of a Hamiltonian flow does not preserve the energy that the underlying flow conserves: on the harmonic oscillator of \cref{sec.wave_equation}, the simulated energy grows without bound for any positive step size. The configuration analog \eqref{eqn.state_update_gradient} (\cref{sec.configuration_dynamics}) is also explicit Euler, but on a gradient flow rather than a Hamiltonian one; on Euclidean parameter spaces, the constant case $\sharp_x=-\eta_{\mathrm{LR}}\sharp_{\mathrm{Euc}}$ is vanilla gradient descent with learning rate $\eta_{\mathrm{LR}}$, which is a standard, well-behaved update for sufficiently small $\eta_{\mathrm{LR}}$. Higher-order or symplectic integrators (e.g.\ Runge-Kutta, leapfrog) can be encoded in the polynomial-coalgebra framework---see~\cite{ngotiaoco2017compositionality} for a Runge-Kutta construction---but the specific cotangent-storage functors developed in this chapter yield only the explicit-Euler form; involving better integrators with our setup is left to future work.
}

All in all, one could tersely denote the coalgebra map as follows:
\begin{multline*}
\Phi_{\phase}(V,\sharp_V,f)\colon
(x,\xi)\mapsto
(\outp m,\omega_M)\mapsto
\Big(
	(\outp n,\omega_N),
	(\xi_N,\inpt n)\mapsto\\
	\big(
		(\xi_M,\inpt m),
		(x+\sharp_x(\xi),\,\xi-\xi_V)
	\big)
\Big),
\end{multline*}
where $\outp n$ is defined in \eqref{eqn.outpn}, $\omega_N$ in \eqref{eqn.omegaprime}, $\xi_M$ and $\xi_V$ in \eqref{eqn.bigtheta}, and $\inpt m$ in \eqref{eqn.inptm}.

%--------------------------------------------------------------------
\section{Configuration dynamics \texorpdfstring{$\Phi_{\conf}$}{Phi conf}}\label{sec.configuration_dynamics}
%--------------------------------------------------------------------

The dynamics functor $\Phi_{\conf}\colon\potlens\to\org$ is the configuration-storage analog of $\Phi_{\phase}$: its state space is the position manifold $V$ (no momentum component), and each step updates $x\mapsto x+\sharp_x(\xi_V)$, where $\xi_V\in V^*$ is the parameter-direction covector assembled from $f$'s backward pass and the differential of its potential. This is the functor we apply to recover Newton's method (\cref{sec.newton_warmup}) and gradient descent (\cref{sec.dl_warmup}).

For configuration-space storage, the functor $\Psi_{\store{\conf}}$ presents a $\cot{V}$-parameter by the store polynomial on $S\coloneqq\absval{V}$:
\[
S\yon^S\To{\theta_V}\cot{V}.
\]
A state consists of a position $x\in V$, and an incoming covector $\xi'\in T^*_xV$ updates that state to $x+\sharp_x(\xi')$ by \eqref{eqn.directions_sharp}. Note that in this case $\sharp$ can depend on $x\in V$. But the majority of what takes place under $\Phi_\mathfrak{s}$ is still compressed within the $\Phi'$ factor from \cref{lem.potlens_to_para_poly}. So as in \cref{sec.phase_dynamics} we now carefully unpack $\Phi_{\conf}$.

\paragraph{The action of $\Phi_{\conf}$ on objects.}
The functor $\Phi_{\conf}$ acts on objects exactly as $\Phi_{\phase}$ in \eqref{eqn.Phi_on_obs}: a position in $\Phi_{\conf}\lensob M$ is a pair $(\outp m,\omega)$ and a direction at $(\outp m,\omega)$ is a pair $(\xi,\inpt m)$, with the same types as in the phase-space case.

\paragraph{The action of $\Phi_{\conf}$ on morphisms.}
Describing the action of $\Phi_{\conf}$ on morphisms will extend to the end of this section, \cref{sec.configuration_dynamics}. Let $(V,\sharp_V):\rvect$ and let
$f\colon V\cdot\lensob M\to\lensob N$
be a morphism in $\potlens$, i.e.\ a tuple $\left(\binom{\inpt f}{\outp f},U\right)$ as in \eqref{eqn.para_potential_lens_maps}. It is sent by $\Phi_{\conf}$ to a $[\Phi_{\conf}\lensob M,\Phi_{\conf}\lensob N]$-coalgebra whose carrier is the underlying set of $V$,
\begin{equation}\label{eqn.state_space_conf}
S\coloneqq\absval{V};
\end{equation}
we write $x\in S=|V|$. The state update below uses the (possibly basepoint-varying) sharp $\sharp_x$ on $V$ from \cref{def.rvect}.

We now unpack the coalgebra function itself,
\[
S\To{\Phi_{\conf}(V,\sharp_V,f)}
\left[\Phi_{\conf}\lensob M,\Phi_{\conf}\lensob N\right]\tri S.
\]
Given a state $x\in S$ and a position $a\coloneqq(\outp m,\omega_M):\outp M\times\Omega(\inpt M)$, the output point $\outp n$, output covector field $\omega_N$, and readout position $b=(\outp n,\omega_N)\in\outp N\times\Omega(\inpt N)$ are defined exactly as in \eqref{eqn.outpn} and \eqref{eqn.omegaprime}. Given a direction $(\xi_N,\inpt n):T^*_{\outp n}\outp N\times\inpt N=\Phi_{\conf}\lensob N[b]$, the coalgebra function $\Phi_{\conf}(V,\sharp_V,f)$ at $(x,a)$ produces the direction $(\xi_M,\inpt m):T^*_{\outp m}\outp M\times\inpt M=\Phi_{\conf}\lensob M[a]$ via \eqref{eqn.inptm} and \eqref{eqn.bigtheta}, exactly as in the phase-space case. The only difference is in the state update: starting from $x$, the state is updated to
\begin{equation}\label{eqn.state_update_gradient}
x+\sharp_x(\xi_V),
\end{equation}
which is the on-directions component of $\theta_V$ \eqref{eqn.directions_sharp} applied to the covector $\xi_V\in V^*$ of \eqref{eqn.bigtheta}. In other words, the state is updated by summing three covectors pulled back along the maps in \eqref{eqn.para_potential_lens_maps}---$\xi_N$ along $\outp f$, $\omega_M(\inpt m)$ along $\inpt f$, and $+1$ along $U$ (yielding $dU$)---projecting to the $V^*$-component, sharpening to a vector via $\sharp_x$, and adding to the original state.

All in all, one could tersely denote the coalgebra map as follows:
\begin{multline*}
\Phi_{\conf}(V,\sharp_V,f)\colon
x\mapsto
(\outp m,\omega_M)\mapsto
\Big(
	(\outp n,\omega_N),
	(\xi_N,\inpt n)\mapsto\\
	\big(
		(\xi_M,\inpt m),
		x+\sharp_x(\xi_V)
	\big)
\Big),
\end{multline*}
where $\outp n$, $\omega_N$, $\xi_M$, $\xi_V$, and $\inpt m$ are as in \eqref{eqn.outpn}, \eqref{eqn.omegaprime}, \eqref{eqn.bigtheta}, and \eqref{eqn.inptm}.

We can now fulfill the promise from \cref{sec.related_cls}.

\begin{proposition}[Eulerized submersion lenses]\label{prop.euler_submersion_lenses}
There is a category $\cat S$, whose objects are submersions, and a diagram
\[
\begin{tikzcd}[column sep=large, row sep=large]
\mathbf{OpenErg}\ar[d, "{\mathrm{collapse}\circ T^*}"'] &
\cat{R}\ar[l, "{\mathrm{wide}}"']\ar[r, "{\mathrm{ff}}"]\ar[d] &
\potlens\ar[d, "\Phi_{\conf}"]\\
\mathbf{COrg} &
\cat{S}\ar[l, "{\mathrm{wide}}"]\ar[r] &
\org
\end{tikzcd}
\]
where the middle vertical functor sends $M$ to the submersion $T^*M\surj M$, and the lower right functor sends a submersion $p\colon E\surj B$ to the polynomial $\sum_{b:B}\yon^{E_b}$.
\end{proposition}

\begin{proof}
Let $\Cat{SLens}$ denote the symmetric monoidal category whose objects are submersions $p\colon E\surj B$ and whose morphisms $p\to p'$, for $p'\colon E'\surj B'$, are smooth maps
\[
\begin{tikzcd}
E\ar[d, ->>, "p"']&
B\times_{B'}E'\ar[l, "\alpha"']\ar[r]\ar[d, ->>]&
E'\ar[d, ->>, "p'"]\\
B\ar[r, equal]&
B\ar[r, "r"']&
B'\ar[ul, phantom, very near end, "\lrcorner"]
\end{tikzcd}
\]
There is a strong symmetric monoidal functor $P\colon\Cat{SLens}\to\poly$ given by
\[
P(E\surj B)\coloneqq\sum_{b:B}\yon^{E_b}
\]
sends a submersion lens $(r,\alpha)\colon p\to p'$ to the polynomial map with forward component $r$ and backward component $\alpha$. It is strong monoidal because the tensor product of submersions is computed by products of total and base spaces.

The strong monoidal functor
\[
\vect_\cong\to\Cat{SLens},
\qquad
V\longmapsto (TV\surj V)
\]
induces an action of $\vect_\cong$ on $\Cat{SLens}$; let $\cat{S}\coloneqq\para{\vect_\cong}{\Cat{SLens}}$. The objects of $\cat S$ are submersions, and a morphism $p\to p'$ in $\cat S$ is a finite-dimensional vector space $V$ and smooth maps
\[
\begin{tikzcd}
V\times E\ar[d, ->>, "V\times p"']&
(V\times B)\times_{B'}E'\ar[l, "{(u,\alpha)}"']\ar[r]\ar[d, ->>]&
E'\ar[d, ->>, "p'"]\\
V\times B\ar[r, equal]&
V\times B\ar[r, "r"']&
B'\ar[ul, phantom, very near end, "\lrcorner"]
\end{tikzcd}
\]

Let $\absval{\blank}\colon\vect_\cong\to\smsetiso$ be the underlying-set functor. For $V:\vect_\cong$ and $p\colon E\surj B$, define a polynomial map
\[
\theta_{V,p}\colon \Store(\absval{V})\otimes P(p)\to P\bigl((TV\surj V)\otimes p\bigr).
\]
Both sides have positions $(x,b)\in V\times B$. Using the canonical identification $TV\cong V\times V$, the map $\theta_{V,p}\colon T_xV\times E_b\to V\times E_b$ on directions at $(x,b)$ is given by
\[
(\dot x,e)\mapsto (x+\dot x,e).
\]
These maps are natural in vector-space isomorphisms and submersion lenses, and monoidal by componentwise addition in direct sums. Thus \cref{prop.para_square} induces a normal lax symmetric monoidal functor
\[
\para{\vect_\cong}{\Cat{SLens}}\to\para{\smsetiso}{\poly}.
\]
Composing with the identification $\para{\smsetiso}{\poly}\cong\org_\cong$ of \cref{prop.org_as_para} and the inclusion $\org_\cong\hookrightarrow\org$ gives a normal lax symmetric monoidal functor $\cat S\to\org$. Unwinding this composite sends the above morphism $(V, r, u,\alpha)$ to the coalgebra with state set $V$ whose action is
\[
x\longmapsto b\longmapsto
\left(
r(x,b),\;
a'\longmapsto\bigl(\alpha(x,b,a'),\,x+u(x,b,a')\bigr)
\right).
\]

The functor $\cat S\to\mathbf{COrg}$ is more straightforward: an $\cat S$-morphism is a vector space $V$ together with a lens $(TV\surj V)\otimes p\to p'$, hence a $\mathbf{COrg}$ morphism with state manifold $V$. It is identity-on-objects, hence wide.

For $\cat{R}$ we take the category $\cat R$ from \cref{sec.related_cls}. We define $\cat R\to\cat S$ on objects by $M\mapsto T^*M\surj M$. On morphisms, send $(V,\sharp_V,w,E)\colon M\to N$ to the $\cat S$-morphism with parameter space $V$, readout $r\coloneqq w$, and for the rest of the data write
\[
dE|_{(x,m)}+(T_{(x,m)}w)^*(\eta)=(\xi_V,\xi_M)\in V^*\oplus T_m^*M
\]
and set $\alpha(x,m,\eta)\coloneqq\xi_M$ and $u(x,m,\eta)\coloneqq\sharp_x(\xi_V)$. Functoriality follows from the chain rule.

The lower-right square commutes as follows. Under the fully faithful functor $\cat R\to\potlens$, the morphism $(V,\sharp_V,w,E)$ is sent to the potentialized lens with output map $w$, unique input map, and potential $E$. Since the input interface is terminal, the only nonzero terms in \eqref{eqn.bigtheta} are
\[
dE|_{(x,m)}+(T_{(x,m)}w)^*(\eta)=(\xi_V,\xi_M).
\]
Thus \eqref{eqn.state_update_gradient} sends the state $x$ to $x+\sharp_x(\xi_V)$ and returns the internal covector $\xi_M$, exactly the coalgebra obtained above from the image of $(V,\sharp_V,w,E)$ in $\cat S$. The remaining compatibility with $\mathbf{OpenErg}$ is the CLS collapse construction restricted to $\cat R$.\qedhere
\end{proof}

Applications of $\Phi_{\conf}$ appear in \cref{sec.newton_warmup} (Newton's method) and \cref{sec.dl_warmup} (gradient descent and backpropagation), and an application of $\Phi_{\phase}$ to a chain of harmonic-oscillator particles, recovering the discrete wave equation, appears in \cref{sec.wave_equation}.

%--------------------------------------------------------------------
\section{Newton's method}\label{sec.newton_warmup}
%--------------------------------------------------------------------

The simplest morphisms in a monoidal category are \emph{scalars}, i.e.\ endomorphisms of the monoidal unit $I$, preserved by normal lax monoidal functors like $\Phi$. In the case of $\potlens$, both interfaces are trivial, $\binom{\rr^0}{\rr^0}$, so $\outp f$ and $\inpt f$ are forced to be the unique map $!$ and the only data is a reactive parameter space $(V,\sharp_V)$ and a potential $U\colon V\to\rr$. Newton's method for finding critical points of a potential is such a scalar. It determines a scalar in $\org$, i.e.\ a discrete dynamical system $V\to[\yon,\yon]\tri V=V$.

Let $\ell\colon V\to\rr$ be a smooth map on a finite-dimensional real vector space $V$. Its derivative $d\ell\colon V\to V^*$ sends $v\in V$ to the gradient covector $d\ell|_v\in V^*$, and the derivative of $d\ell$ at $v$ is itself a linear map
\begin{equation}\label{eqn.hessian}
T_v(d\ell)\colon V\to V^*,
\end{equation}
called the \emph{Hessian} of $\ell$ at $v$. In a basis $e_1,\ldots,e_n$ of $V$, the linear map $T_v(d\ell)$ is given by the matrix of second partial derivatives
\[
\bigl(T_v(d\ell)\bigr)_{ij}=\partial_i\partial_j\ell(v),
\]
which is symmetric by equality of mixed partials. Newton's method requires this matrix to have full rank at every $v\in V$, so that $T_v(d\ell)$ is an isomorphism, and this is the case where our framework applies (\cref{def.rvect}): put
\[
\sharp_v\coloneqq-\bigl(T_v(d\ell)\bigr)^{-1}\colon V^*\To{\cong}V,
\]
so $(V,\sharp_V)\in\rvect$. So we now have a scalar in $\potlens$
\[
\bigl((V,\sharp_V),\ \outp f=!,\ \inpt f=!,\ U=\ell\bigr)\colon I\to I
\]
with potential $\ell$. 

Applying $\Phi_{\conf}$ to $(V,\sharp_V,!,!,\ell)$ gives a coalgebra carried by state set $\absval V$; in \eqref{eqn.bigtheta} the $\xi_N$- and $\omega_M$-summands vanish, leaving only $dU=d\ell|_v$, and the state update \eqref{eqn.state_update_gradient} reads
\[
v\longmapsto v+\sharp_v(d\ell|_v)=v-\bigl(T_v(d\ell)\bigr)^{-1}(d\ell|_v),
\]
one step of \emph{Newton's method} for finding a critical point of $\ell$. Whether or not this dynamical system $V\to V$ converges to a critical point is a separate question.%
\footnote{If one wants to output the stream of $V$'s, rather than have them remain hidden as internal states, use the interface $\binom{\rr^0}{V}$, the identity as $\outp{f}$, and project out the new factor to keep the previous potential $V\times V\To{\pi} V\To{U}\rr$.}

\section{Gradient descent and backpropagation}\label{sec.dl_warmup}
%--------------------------------------------------------------------

By \emph{deep learning} we mean the training of an artificial neural network. Applying \cref{prop.lens_inclusion} with $\cat C=\mfd$ and $\Fun T=\rr\times\blank$ gives a strong symmetric monoidal functor $\inc\colon\mfd\to\lmfd^\rr$, $M\mapsto\binom{\rr^0}{M}$. Whiskering with $\para\rvect{-}$ and composing with $\Phi_{\conf}$ yields a normal lax symmetric monoidal functor
\[\para{\rvect}{\mfd}\To{\para{\rvect}{\inc}}\potlens\To{\Phi_{\conf}}\org,\]
whose composite we denote $\lrn$. One could say that training a neural network is a case of our configuration dynamics construction, in the case that input manifolds and potentials are trivial: $\inpt M=\rr^0$ and $U=0$.

{\emergencystretch=2em
We now unfold this construction in coordinates, taking the source and target manifolds---the input and output layers of the neural network---to be $\rr^m$ and $\rr^n$.
\par}

\paragraph{A parameterized map as a smooth rewiring diagram.}
Let $F\colon V\times\rr^m\to\rr^n$ be a smooth parameterized map, thought of as a feedforward neural network with parameter space $(V,\sharp_V):\rvect$---i.e., $V$ comes equipped with a smooth section $\sharp_V\colon V\to\Iso(V^*,V)$ (\cref{def.rvect}), whose value $\sharp_x\colon V^*\To{\cong}V$ at $x\in V$ will act as a position-dependent learning-rate. This $F$ is regarded by $\para{\rvect}{\inc}$ as a $\potlens$-morphism
\[
f\colon\binom{\rr^0}{\rr^m}\to\binom{\rr^0}{\rr^n}
\]
with parameter $V$, by taking $\outp f=F\colon V\times \rr^m\to\rr^n$, taking $\inpt f\colon V\times\rr^m\times\rr^0\to\rr^0$ to be the unique map, and taking the potential to be $0$. 

\paragraph{The interfaces.}
On objects, $\lrn(\rr^m)$ is given by
\[
\lrn(\rr^m)=\Phi_{\conf}\binom{\rr^0}{\rr^m}
=\cot{\rr^m}\otimes\ihom{\cot{\rr^0},\yon}
\cong\cot{\rr^m}=\sum_{z:\rr^m}\yon^{T^*_z\rr^m},
\]
because $\cot{\rr^0}\cong\yon$ and $\ihom{\yon,\yon}\cong\yon$. Hence $\Phi_{\conf}(f)$ is a $[\cot{\rr^m},\cot{\rr^n}]$-coalgebra.

\paragraph{The coalgebra.}
Because we are using configuration storage, the state set is $\absval{V}$ by \eqref{eqn.state_space_conf}; an element is a vector of the ``weights and biases'' of the artificial neural network. We unpack the coalgebra step at fixed $x\in V$, given an input position $z\in\rr^m$ from upstream and a direction $\xi\in T^*_{F(x,z)}\rr^n$ from downstream; where these come from during the training process is taken up below.

At state $x\in V$ and input data $z\in\rr^m$, the readout point is
\begin{equation}\label{eqn.dl_readout}
\outp n\coloneqq\outp f(x,z)=F(x,z),
\end{equation}
which is \eqref{eqn.outpn} in this special case.

Now we feed the external interface a direction $\xi\in T^*_{F(x,z)}\rr^n$. Since $\inpt f$ is the unique map to $\rr^0$ and $U=0$, the second and third summands in \eqref{eqn.bigtheta} vanish. Thus the only nonzero contribution is the cotangent pullback along $F$:
\begin{equation}\label{eqn.dl_pullback}
(\xi_V,\xi_M)=(T_{(x,z)}F)^\top\xi\in V^*\oplus T^*_z\rr^m.
\end{equation}
Here $\xi_V$ is the parameter covector and $\xi_M$ is the covector returned to the $\binom{\rr^0}{\rr^m}$ interface. In partial-map notation,
\[
\xi_V=\bigl(T_x(F(\blank,z))\bigr)^\top\xi
\qqand
\xi_M=\bigl(T_z(F(x,\blank))\bigr)^\top\xi.
\]
By \eqref{eqn.state_update_gradient}, the parameter update is therefore
\begin{equation}\label{eqn.dl_gradient_update}
x\longmapsto x+\sharp_x(\xi_V).
\end{equation}
Altogether, suppressing the unique $\rr^0$-components, the coalgebra is
\[
\Phi_{\conf}(F)(x)(z)
=\Bigl(F(x,z),\;\xi\mapsto\bigl(\xi_M,\,x+\sharp_x(\xi_V)\bigr)\Bigr),
\]
where $(\xi_V,\xi_M)$ is defined by \eqref{eqn.dl_pullback}.

\paragraph{Losses and backpropagation.}
The zero-potential condition does not mean there is no learning signal; it means the learning signal is supplied as an external cotangent direction. If $\xi=d\ell|_{F(x,z)}$ for a loss $\ell\colon\rr^n\to\rr$, then by the chain rule
\[
d(\ell\circ F)|_{(x,z)}=(T_{(x,z)}F)^\top d\ell|_{F(x,z)}=(\xi_V,\xi_M).
\]
Thus $\xi_V=d_x(\ell(F(\blank,z)))$ is the parameter-gradient covector, while $\xi_M=d_z(\ell(F(x,\blank)))$ is the covector propagated backward to the previous interface, if any. For a composite network, this repeated production of the covector $\xi_M$ is the usual backpropagated gradient signal. On Euclidean parameter spaces, for the constant sharp $\sharp_x=-\eta_{\mathrm{LR}}\sharp_{\mathrm{Euc}}$, \eqref{eqn.dl_gradient_update} is vanilla gradient descent with learning rate $\eta_{\mathrm{LR}}$. This presupposes a single fixed loss $\ell$ applied at every step; in actual training, $\ell$ varies per datum (typically through a label), and the source of $z$ varies too. We package both as a single coalgebra next.

\paragraph{Training data as an environment.}
The preceding discussion focuses on $\xi=d\ell|_{F(x,z)}$ for a single fixed loss function $\ell\colon\rr^n\to\rr$ and a single input $z\in\rr^m$. Genuine training involves a stream of such pairs, which we package as an $\org$-map $\delta_{\mathrm{gen}}\colon\yon\to\Phi_{\conf}\binom{\rr^n}{\rr^m}$, i.e.\ a coalgebra on
\[
\cot{\rr^m}\otimes\ihom{\cot{\rr^n},\yon}
\]
whose positions are pairs $(z,\omega)\in\rr^m\times\Omega(\rr^n)$: an input point together with a covector field on the output (typically $\omega=d\ell$ for some per-datum loss $\ell\colon\rr^n\to\rr$). Such a coalgebra is, in general, not just a stream of $(z,\omega)$'s, but can branch after each step based on a pair $(\xi_M,y)\in T^*_z\rr^m\times\rr^n$. These are exactly what the network gives back when we wire it in, below: $y=F(x,z)$ is the predicted output and $\xi_M$ is the backpropagated input-gradient. So the training-data block emits $(z,\omega)$ and may transition based on what the network replies, namely the prediction $y$ and the backpropagated input-gradient $\xi_M$. When the transition of the data generator depends on these replies, the data presented to the model-in-training is adapted to that model's behavior; when it ignores them, the data presentation is simply an externally specified supervised stream.

We can combine $\delta_{\mathrm{gen}}$ with the network $\lrn(F)\colon\cot{\rr^m}\to\cot{\rr^n}$ as follows. By closedness of $\org$ (\cref{rmk.org_closed}), $\lrn(F)$ corresponds equivalently to a map
\[
\overline{\lrn(F)}\colon\yon\to[\cot{\rr^m},\cot{\rr^n}]
\]
in $\org$. Tensoring with $\delta_{\mathrm{gen}}$ and applying the two evaluation pairings of $\poly$ closes the system:
\[
\yon\To{\delta_{\mathrm{gen}}\otimes\overline{\lrn(F)}}\bigl(\cot{\rr^m}\otimes\ihom{\cot{\rr^n},\yon}\bigr)\otimes[\cot{\rr^m},\cot{\rr^n}]\To{\ev_1}\cot{\rr^n}\otimes\ihom{\cot{\rr^n},\yon}\To{\ev_2}\yon.
\]
The result is a $\yon$-coalgebra on $\absval{V}\times\absval{V_{\mathrm{gen}}}$, where $V_{\mathrm{gen}}$ is the carrier of $\delta_{\mathrm{gen}}$, i.e.\ a discrete dynamical system on $V\times V_{\mathrm{gen}}$ that trains the neural network as it moves through training data. In each step, starting from the current network parameter $x\in V$ and dataset state $s\in V_{\mathrm{gen}}$: $\delta_{\mathrm{gen}}$ at $s$ produces $(z,\omega)$; $\ev_1$ pairs $\cot{\rr^m}$ (carrying $z$) with $[\cot{\rr^m},\cot{\rr^n}]$ to run the network, producing $y=F(x,z)$; $\ev_2$ pairs $[\cot{\rr^n},\yon]$ (carrying $\omega$) with the resulting $\cot{\rr^n}$, sampling $\xi=\omega(y)$ and triggering the backward pass; update $x\mapsto x+\sharp_x(\xi_V)$, and advance $\delta_{\mathrm{gen}}$'s state via its coalgebra map applied to $(\xi_M,\,y)$.

\section{The wave equation}\label{sec.wave_equation}
%--------------------------------------------------------------------

We illustrate $\Phi_{\phase}\colon\potlens\to\org$ by deriving the wave equation. We describe a single particle (with harmonic potential) as a $0$-ary $\potlens$-morphism $\Part\colon I\to\boxob$ and arrange particles into a chain as a $K$-ary wiring morphism $\fun{wire}_K\colon\boxob\tpow{K}\to\boxob$, then illustrate functoriality of $\Phi_{\phase}$ by computing the wave equation in two different ways. In \cref{sec.spring_first_pass} we compose the particles and the wiring inside $\potlens$, apply $\Phi_{\phase}$, and recover the discrete wave equation. In \cref{sec.spring_second_pass} we instead apply $\Phi_{\phase}$ to the particle and wiring separately and compose the resulting coalgebras in $\org$, showing that we again obtain the wave dynamics.

That is, we begin with a single particle with position and momentum, which we put in a ``box'' that in some sense delivers the particle's position to its neighbors and updates its state based on some fixed parameters $\kappa,m>0$ and the locations of its neighboring particles. We wire these boxes together in series
\begin{equation}\label{eqn.wave_wd}
\begin{tikzpicture}[oriented WD, bb port length=4pt, bb port sep=1.5, bb min width=.35cm, bbx=.4cm, bby=.8ex, baseline=(lbox1), particle/.style={path picture={\fill (path picture bounding box.center) circle (2.4pt);}}]
  \def\N{7}
  \node[bb={1}{1}, particle] (lbox1) {};
  \foreach \i [evaluate=\i as \prev using int(\i-1)] in {2,...,\N} {
    \node[bb={1}{1}, particle, right=.7 of lbox\prev] (lbox\i) {};
    \draw (lbox\prev_out1) -- (lbox\i_in1);
  }
  \node[right=.4 of lbox\N] (dots) {$\cdots$};
  \draw (lbox\N_out1) -- (dots.west);
  \node[bb={1}{1}, particle, right=.4 of dots] (rbox1) {};
  \draw (dots.east) -- (rbox1_in1);
  \foreach \i [evaluate=\i as \prev using int(\i-1)] in {2,...,\N} {
    \node[bb={1}{1}, particle, right=.7 of rbox\prev] (rbox\i) {};
    \draw (rbox\prev_out1) -- (rbox\i_in1);
  }
  \node[bb={0}{0}, fit={(lbox1) (rbox\N)}] (Y) {};
  \node[coordinate] at (Y.west|-lbox1_in1) (Y_in1) {};
  \node[coordinate] at (Y.east|-rbox\N_out1) (Y_out1) {};
  \draw (Y_in1) -- (lbox1_in1);
  \draw (rbox\N_out1) -- (Y_out1);
\end{tikzpicture}
\end{equation}
and calculate that the resulting state dynamics evolves according to the discrete wave equation:%
\footnote{Taking the continuum limit gives the usual wave equation.}
\begin{equation}\label{eqn.discrete_wave}
m\ddot x_i=\kappa(x_{i-1}-2x_i+x_{i+1}),
\end{equation}
where $\ddot x_i(t)=x_i(t+2)-2x_i(t+1)+x_i(t).$

We will work in the full suboperad of $\potlens$ (in the sense of \cref{sec.wd_operads}) spanned by a single object $\boxob\coloneqq\binom{\rr}{\rr}$, corresponding to a box whose input port and output port are both $\rr$. That is, we'll consider morphisms of the form
\[
\varphi:\potlens(\boxob\tpow{n},\boxob)
\]
for varying $n$. Note that $\boxob\tpow{0}=\binom{\rr^0}{\rr^0}$ is the monoidal unit.

We give the derivation in two passes. In the first pass, we describe the particle and the wiring inside $\potlens$, compose them there, and apply $\Phi_{\phase}$ to the resulting $0$-ary $\potlens$-morphism to read off the dynamics. In the second pass, by functoriality and the lax monoidal structure of $\Phi_{\phase}$, we instead apply $\Phi_{\phase}$ to the particle and to the wiring separately, then compose in $\org$; the result is the same.

\subsection{First pass: composing in \texorpdfstring{$\potlens$}{PLens}}\label{sec.spring_first_pass}

First we give a $0$-ary morphism $\Part\colon\binom{\rr^0}{\rr^0}\to\binom{\rr}{\rr}$, for the dynamical system that goes in each internal box, representing the particle of mass $m>0$. Then we give a $K$-ary morphism for each $K>0$ that describes the (static) wiring diagram shown in \eqref{eqn.wave_wd}. Then we calculate what happens when we compose.

\paragraph{The particle.}

To define a particle $\Part\colon\binom{\rr^0}{\rr^0}\to\binom{\rr}{\rr}$ in $\potlens$ \eqref{eqn.para_potential_lens_maps}, we need a reactive vector space $(V,\sharp_V)$, a smooth ``forward'' map $\outp f\colon V\to\rr$, and a smooth ``potential'' $U\colon V\times\rr\to\rr$. We take the parameter space to be $\rr\in\rvect$ with constant sharp $\sharp_v(p)\coloneqq p/m$ (independent of $v\in\rr$). We take the forward map to be the identity, $\outp f(x)\coloneqq x$, and the potential to be
\[U(x,y)\coloneqq\tfrac{\kappa}{2}(x-y)^2.\] 
This is called the \emph{harmonic} potential.

\paragraph{The wiring diagram.}
For the wiring diagram, we start in $\Lens{\finset\op}$; see \cref{ex.lens_finsetop}. The $K$-ary series composition shown in \eqref{eqn.wave_wd} corresponds to a lens $\phi_K\colon\binom{K}{K}=\binom{1}{1}+\cdots+\binom{1}{1}\to\binom{1}{1}$ given by
\[
K\From{\outp f}1
\qqand
K+1\From{\inpt f} K,
\]
where we identify $K+1$ with the disjoint union of the $K$ internal-box outputs and the external-box input, the external-box input last. Then $\outp f$ picks out the last wire, $\outp{f}(*)=K$, and $\inpt f$ picks out the preceding wire for each internal input: the first internal input is fed by the external input, and input $n>1$ is fed by output $n-1$.

Applying $\rr^-$ from \cref{lemma.lens_rr}, we obtain the lens $\binom{\rr^K}{\rr^K}\to\binom{\rr}{\rr}$ given by
\[
\outp f(x_1,\ldots,x_K)\coloneqq x_K
\qqand
\inpt f\bigl((x_1,\ldots,x_K),\,x_0\bigr)\coloneqq(x_0,\,x_1,\,\ldots,\,x_{K-1}).
\]
{\emergencystretch=2em
Lenses without potential and without parameterization are special cases of $\potlens$\allowbreak-morphisms, i.e.\ taking $V'\coloneqq\rr^0$ and the $0$-potential $U'\coloneqq0\colon\rr^K\times\rr\to\rr$, we have the wiring as a $\potlens$\allowbreak-morphism
\par}
\[
\fun{wire}_K\colon\boxob\tpow{K}\to\boxob,\qquad \left(\binom{\inpt f}{\outp f},0\right)
\]

Composing, we obtain a $0$-ary map, $\fun{wire}_K(\Part,\ldots,\Part)$ in $\potlens$, with parameter $V\coloneqq V'\oplus\rr^{\oplus K}=\rr^K$ (one $\rr$ per particle) and constant sharp
\begin{equation}\label{eqn.sharp_chain}
\sharp_v\colon V^*\to V,\qquad p\mapsto p/m,
\end{equation}
acting per-particle on each $\rr$-summand (the inverse-mass pairing), independent of $v\in V$. The defining maps are
\[
\outp f(x_1,\ldots,x_K)\coloneqq x_K
\qqand
U\bigl((x_1,\ldots,x_K),\,x_0\bigr)\coloneqq\sum_{i=1}^{K}\tfrac{\kappa}{2}(x_i-x_{i-1})^2,
\]
with $\inpt f$ vacuous. The sum in $U$ comes from the productor \eqref{eqn.monoid_productor} of the monoidal monad $\rr\times\blank$ on $\Lens\mfd$, where $(\rr,0,+)$ is the additive monoid. Composition with $\fun{wire}_K$ then substitutes $y_i\mapsto x_{i-1}$ via $\inpt f$ (with $x_0$ the external input).

\paragraph{The discrete dynamics.}

The discrete dynamics appear when we apply the functor $\Phi_{\phase}\colon\potlens\to\org$. The object $\boxob$ is sent to
\[
\Phi_{\phase}(\boxob)=\sum_{(x,\omega):\rr\times\Omega(\rr)}\yon^{T^*_x\rr\times \rr}.
\]
The map $\fun{wire}_K(\Part,\ldots,\Part)$ is sent to a coalgebra
\[
\Phi_{\phase}(\fun{wire}_K(\Part,\ldots,\Part))\colon S\To{}\Phi_{\phase}(\boxob)\tri S
\]
with state set $S\coloneqq T^*\rr^K$, with elements written $s=((x_1,\ldots,x_K),(p_1,\ldots,p_K))$ for positions and momenta (so $\xi=\vec p$ in terms of \eqref{eqn.state_update}), and with the function given by
\begin{equation}\label{eqn.wave_coalg}
(\vec x,\vec p)\mapsto\Bigl(\bigl(x_K,\,\omega_\boxob\bigr),\;(\xi_N,x_0)\mapsto\bigl(\vec x+\tfrac{1}{m}\vec p,\,\vec p-\xi_V\bigr)\Bigr),
\end{equation}
where each piece is read off from the unpacking in \cref{sec.phase_dynamics}:
\begin{itemize}
\item The output position $x_K$ comes from $\outp f$ via \eqref{eqn.outpn}.
\item The \emph{harmonic spring} covector field on the left-hand side,
\[\omega_\boxob(x_0)=d\bigl[\tfrac{\kappa}{2}(x_1-x_0)^2\bigr]\big|_{x_0}=-\kappa(x_1-x_0),\]
comes from \eqref{eqn.omegaprime} (with $\inpt f$ and $\omega_M$ vacuous, and $dx_0=+1$ via \eqref{eqn.d_potential}).
\item The pullback covector $\xi_V\in T^*_{\vec x}V$ comes from \eqref{eqn.bigtheta}. It is given component-wise (via \eqref{eqn.tangent_vec} identifying $T^*_{\vec x}V\cong V^*=(\rr^K)^*$) by
\begin{align*}
(\xi_V)_i&=
\bigl((T_{\vec x}\outp f)^\top\xi_N\bigr)_i+\partial_{x_i}U(\vec x,x_0)\\&=
\begin{cases}\partial_{x_i}U(\vec x,x_0)+0&1\leq i<K\\ \partial_{x_K}U(\vec x,x_0)+\xi_N&i=K\end{cases}\\&=
\begin{cases}\kappa(2x_i-x_{i-1}-x_{i+1})&1\leq i<K\\ \kappa(x_K-x_{K-1})+\xi_N&i=K\end{cases}
\end{align*}
\item The state update applied to $s=(\vec x,\vec p)$ comes from \eqref{eqn.state_update}: using our (constant) sharp $\sharp_{\vec x}(\vec p)=\vec p/m$ from \eqref{eqn.sharp_chain} and the symplectic sharp $\sharp_S\colon(\xi,x)\mapsto(x,-\xi)$ from \eqref{eqn.sharp_S}, we get
\[
s'\coloneqq s+\sharp_S(\xi_V,\sharp_{\vec x}(\vec p))=(\vec x+\vec p/m,\,\vec p-\xi_V).
\]
In other words, writing $s'=(x_1',\ldots,x_K',p_1',\ldots,p_K')$, we have
\begin{equation}\label{eqn.potlens_composite_final}
x_i'\coloneqq x_i+p_i/m
\qqand
p_i'\coloneqq\begin{cases}p_i+\kappa(x_{i-1}+x_{i+1}-2x_i)&1\leq i<K\\ p_i+\kappa(x_{K-1}-x_K)-\xi_N&i=K.\end{cases}
\end{equation}
\end{itemize}

\paragraph{Recovering the wave equation.}
To recover the discrete wave equation everywhere, we pin the chain between a left and right wall:
\begin{equation}\label{eqn.wave_pin}
  x_0\coloneqq 0
  \qqand
  x_{K+1}\coloneqq L(K+1)
\end{equation}
where $L$ is the equilibrium spacing between adjacent particles. Supplying these via the external direction-input means setting
\begin{equation}\label{eqn.wave_bc}
x_0\coloneqq 0\qqand\xi_N\coloneqq \kappa\bigl(x_K-L(K+1)\bigr).
\end{equation}
With these choices, the boundary case at $i=K$ becomes $p_K'=p_K+\kappa\bigl(x_{K-1}+L(K+1)-2x_K\bigr)$, so the above state update formula reduces to this:
\begin{equation}\label{eqn.state_update_explicit}
x_i'\coloneqq x_i+p_i/m
\qqand
p_i'\coloneqq p_i+\kappa(x_{i-1}+x_{i+1}-2x_i).
\end{equation}

We then think of the state $s$ as a function of time: fix any initial $s(0)\coloneqq(\vec{x}(0),\vec{p}(0))$ and set $s(t+1)\coloneqq s(t)'$ as in \eqref{eqn.state_update_explicit}. We then rewrite the first equation as $p_i(t)=mx_i(t+1)-mx_i(t)$ and substitute it into the second:
\[
mx_i(t+2)-mx_i(t+1)=mx_i(t+1)-mx_i(t)+\kappa(x_{i-1}(t)+x_{i+1}(t)-2x_i(t))
\]
Rearranging, we obtain the wave equation formula \eqref{eqn.discrete_wave} with the same notation as used there.

\begin{proposition}\label{prop.wave_equation}
\leavevmode\par\nobreak
With $\Part$, $\fun{wire}_K$, and the boundary choices \eqref{eqn.wave_pin} and \eqref{eqn.wave_bc} as above, the $\Phi_{\phase}(\boxob)$-coalgebra
\[
\Phi_{\phase}\bigl(\fun{wire}_K(\Part,\ldots,\Part)\bigr)
\]
recovers the discrete wave equation \eqref{eqn.discrete_wave}.
\end{proposition}
\begin{proof}
This is the calculation of \eqref{eqn.state_update_explicit}: writing the state as a function of time and eliminating the momenta gives \eqref{eqn.discrete_wave}.
\end{proof}

\subsection{Second pass: composing in \texorpdfstring{$\org$}{Org}}\label{sec.spring_second_pass}

We have now recovered the wave equation by connecting $K$-many particles together in $\potlens$, sending the result to $\org$ and investigating the discrete dynamical system (the $(\cot{\rr}\otimes[\cot{\rr},\yon])$-coalgebra) as a function of time. This is the left-hand side below, which agrees with the right-hand side by functoriality and the lax monoidal structure of $\Phi_{\phase}$:
\[
\Phi_{\phase}\bigl(\fun{wire}_K(\Part,\ldots,\Part)\bigr)=\Phi_{\phase}(\fun{wire}_K)\bigl(\Phi_{\phase}(\Part),\ldots,\Phi_{\phase}(\Part)\bigr),
\]
which is the $K$-ary composite, taken in $\org$, of $K$ copies of the single-particle dynamical system $\Phi_{\phase}(\Part)$ wired together via $\Phi_{\phase}(\fun{wire}_K)$. Although the equality above already determines the result, we work out this second composite explicitly as a check on the formula.

\paragraph{The particle dynamics.}

We first apply $\Phi_{\phase}$ to $\Part\colon\binom{\rr^0}{\rr^0}\to\boxob$ to obtain a coalgebra on
\[
  \left[\Phi_{\phase}\binom{\rr^0}{\rr^0},\Phi_{\phase}(\boxob)\right]=
  \left[\yon,\Phi_{\phase}(\boxob)\right]\cong\Phi_{\phase}(\boxob)=
  \sum_{(x,\omega):\rr\times\Omega(\rr)}\yon^{T^*_x\rr\times\rr}
\]
We took the parameter space to be $\rr$, so by \eqref{eqn.state_space} the state set of $\Phi_{\phase}(\Part)$ is $S\coloneqq T^*\rr$, with elements written $s=(x,p)$ for position and momentum. The map
\[
S\To{\Phi_{\phase}(\Part)}
\sum_{(x,\omega):\rr\times\Omega(\rr)}S^{T^*_x\rr\times\rr}
\]
is given by
\[
(x,p)\mapsto\Bigl(\bigl(x,\,x_{\fun{prev}}\mapsto\kappa(x_{\fun{prev}}-x)\bigr),\;(\xi_{\fun{next}},x_{\fun{prev}})\mapsto\bigl(x+p/m,\,p-\xi_{\fun{next}}+\kappa(x_{\fun{prev}}-x)\bigr)\Bigr).
\]
In other words, starting at position $x$ and momentum $p$, it outputs $x$ to the right and the covector field $x_{\fun{prev}}\mapsto\kappa(x_{\fun{prev}}-x)$, which ``pulls'' $x_{\fun{prev}}$ toward $x$. Then, receiving a covector $\xi_{\fun{next}}$ from the right and a point $x_{\fun{prev}}$ from the left, it updates its position by adding velocity (momentum divided by mass) and updates its momentum by adding the spring force $\kappa(x_{\fun{prev}}-x)$, which ``pulls'' $x$ toward $x_{\fun{prev}}$, and subtracting the received covector $\xi_{\fun{next}}$.
 
\paragraph{The static wiring.}

Apply $\Phi_{\phase}$ to $\fun{wire}_K\colon\boxob^{\otimes K}\to\boxob$. With trivial parameter $\rr^0$, the state space $T^*\rr^0$ is a single point, so $\Phi_{\phase}(\fun{wire}_K)$ is \emph{static}: a function $1\to[\Phi_{\phase}(\boxob)^{\otimes K},\allowbreak\Phi_{\phase}(\boxob)](1)$ is equivalently (see \eqref{eqn.dirichlet_hom}) a polynomial map $\Phi_{\phase}(\boxob)^{\otimes K}\to\allowbreak\Phi_{\phase}(\boxob)$, i.e.\
\begin{multline*}
\sum_{(\vec x,\vec\omega):\rr^K\times\Omega(\rr)^K}\yon^{T^*_{\vec x}\rr^K\times\rr^K}\\
\To{\Phi_{\phase}(\fun{wire}_K)}
\sum_{(x,\omega):\rr\times\Omega(\rr)}\yon^{T^*_x\rr\times\rr}.
\end{multline*}
To each $(\vec x,\vec \omega)$, the vector of outputs of the internal boxes, we assign the external output $(x_K,\omega_1)$ (the rightmost particle's position with the leftmost box's covector field); and to each external input $(\xi_N,x_0)$ at the external box, we assign the internal inputs $(\omega_2(x_1),x_0)$, $(\omega_3(x_2),x_1)$, $\ldots$, $(\omega_K(x_{K-1}),x_{K-2})$, $(\xi_N,x_{K-1})$---each box $i<K$ receives its right neighbor's covector field evaluated at $x_i$ in its $\xi$-slot, box $K$ gets the external $\xi_N$, and each box receives its left neighbor's position. In our concise format,
\begin{equation}\label{eqn.org_wiring_concise}
(\vec x,\vec \omega)\mapsto\Big((x_K,\omega_1),\;(\xi_N,x_0)\mapsto\bigl((\omega_2(x_1),\ldots,\omega_K(x_{K-1}),\xi_N),\,(x_0,x_1,\ldots,x_{K-1})\bigr)\Big).
\end{equation}
The routing $\omega_{i+1}(x_i)$ into box $i$'s $\xi$-slot is how the wiring transmits the spring force from box $i+1$ to box $i$; the only external forcing is via $x_0$ (the leftmost neighbor position, fed to box $1$) and $\xi_N$ (the covector at $x_K$, fed to box $K$) in \eqref{eqn.wave_wd}.

\paragraph{Composition.}

The $\org$-composite $\Phi_{\phase}(\fun{wire}_K)\bigl(\Phi_{\phase}(\Part),\ldots,\Phi_{\phase}(\Part)\bigr)$ is a $0$-ary morphism $\yon\to\Phi_{\phase}(\boxob)$ in $\org$, i.e.\ a $\Phi_{\phase}(\boxob)$-coalgebra. By \cref{prop.org_as_para}, composition in $\org$ multiplies state spaces and composes the underlying polynomial maps; here $\Phi_{\phase}(\fun{wire}_K)$ has trivial state space and each $\Phi_{\phase}(\Part)$ has state space $T^*\rr$, so the composite has state space $1\times(T^*\rr)^K=T^*\rr^K$. Concretely, the $K$-many single-particle coalgebra maps $\Phi_{\phase}(\Part)\colon T^*\rr\to\Phi_{\phase}(\boxob)\tri T^*\rr$ combine via the lax monoidal structure of $\blank\coalg$ (\cref{prop.org}) into a single $\Phi_{\phase}(\boxob)^{\otimes K}$-coalgebra with states $T^*\rr^K$, and the static polynomial map $\Phi_{\phase}(\fun{wire}_K)\colon\Phi_{\phase}(\boxob)^{\otimes K}\to\Phi_{\phase}(\boxob)$ then post-composes:
\[
T^*\rr^K\To{\Phi_{\phase}(\Part)^{\otimes K}}\Phi_{\phase}(\boxob)^{\otimes K}\tri T^*\rr^K\To{\Phi_{\phase}(\fun{wire}_K)\tri T^*\rr^K}\Phi_{\phase}(\boxob)\tri T^*\rr^K.
\]
Given a tuple $(\vec x,\vec p):T^*\rr^K$, the first arrow sends it to
\begin{equation}\label{eqn.lots_coalgebras}
\Bigl(\bigl(x_i,\,x_i'\mapsto\kappa(x_i'-x_i)\bigr)_{i=1}^K,\;(\vec\xi_{\fun{next}},\vec x_{\fun{prev}})\mapsto\bigl(\vec x+\vec p/m,\,\vec p-\vec\xi_{\fun{next}}+\kappa(\vec x_{\fun{prev}}-\vec x)\bigr)\Bigr).
\end{equation}
When applying the second arrow \eqref{eqn.org_wiring_concise} to the result, the threading goes as follows. 

Beginning with $(\vec x,\vec p):T^*\rr^K$, the coalgebras output $(\vec x,\vec\omega)\coloneqq\bigl(x_i,\,x_i'\mapsto\kappa(x_i'-x_i)\bigr)_{i=1}^K$. The wiring takes that, outputs the last point and the first covector field, $(x_K,\omega_1)$, and asks for $(\xi_N,x_0)$. Upon receiving it, it sends $\bigl((\omega_2(x_1),\ldots,\omega_K(x_{K-1}),\xi_N),\,(x_0,x_1,\ldots,x_{K-1})\bigr)$ back to the coalgebras. In other words, it sends $(\vec\xi_{\fun{next}},\vec x_{\fun{prev}})$ where $(\xi_{\fun{next}})_i\coloneqq\omega_{i+1}(x_i)=\kappa(x_i-x_{i+1})$ for $1\leq i<K$ and $(\xi_{\fun{next}})_K\coloneqq\xi_N$, and $(x_{\fun{prev}})_i=x_{i-1}$. This in turn is sent to $(\vec x+\vec p/m,\,\vec p-\vec\xi_{\fun{next}}+\kappa(\vec x_{\fun{prev}}-\vec x))$. This is exactly the same as \eqref{eqn.potlens_composite_final}, verifying the functor and auditing the validity of the formulas in this case.

\begin{remark}\label{rmk.wave_generalizations}
The construction generalizes. Replacing $\rr$ by $\rr^d$ as the box object and replacing the chain by any $K$-ary wiring---e.g.\ a $d$-dimensional cubic lattice---gives the discrete wave equation $m\ddot x_i=\kappa\sum_{j\sim i}(x_j-x_i)$ on that lattice, where $\sim$ is the neighbor relation.
\qedhere
\end{remark}
